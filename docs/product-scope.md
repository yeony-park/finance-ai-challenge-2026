# 제품 목표와 범위

## 한 문장 목표

JeomJeom은 미술품 조각투자 상품의 공시, 작품 정보, 공개 시장 근거와 플랫폼 이력을 연결해 금융소비자가 확인된 사실과 남은 위험을 구분하도록 돕는다.

## 제공

- 공시·공식 문서의 사실 필드와 원문 링크
- 공모가격 구성, 작품 식별, 비교 표본, 회수·플랫폼 이력의 분리 표시
- 기준일, 출처 상태, 누락과 현재성 경고
- 근거가 연결된 쉬운 설명과 확인 질문

## 제공하지 않음

- 개인화된 매수·매도 추천
- 수익률·가격 예측 또는 원금 보장
- 공식 감정평가, 진위 판정, 법률 검토 대체
- 근거 없는 시세 또는 인과관계 생성

## 최소 evidence 구조

`claim`, `value`, `unit`, `source_url`, `as_of`, `fetched_at`, `subject_id`, `status`, `method`, `limitations`을 유지한다. 확인할 수 없는 값은 추정하지 않고 `null`, `미확인`, `판정 보류`로 표시한다.
