# 미술품 조각투자 서비스 화면 명세

- 문서 상태: **CURRENT · CANONICAL**
- 관련 문서: [제품](./ART_INVESTMENT_PRODUCT_SPEC.md) · [정보 구조](./ART_INVESTMENT_INFORMATION_ARCHITECTURE.md) · [AI](./ART_INVESTMENT_AI_SPEC.md)

## 1. 공통 화면 규칙

### 공통 프레임

- `GlobalHeader → main(PageContainer) → GlobalFooter` 순서다.
- 금융 분석 서비스의 중립 배경, 높은 대비, 규칙적인 숫자 정렬을 사용한다. 작품 이미지는 식별용이며 판단·근거보다 우선하지 않는다.
- 동일 `ProductCard`, `ArtistCard`, `PlatformCard`, 판단 badge, MetricCard, 표, 상태 UI를 재사용한다.
- 빨강/초록만으로 판단하지 않고 아이콘+라벨+설명을 함께 쓴다. 네온, 장식용 3D, 과도한 gradient와 animation을 금지한다.
- 모든 차트에 제목, 축/단위, 범례, 기준일, 텍스트 요약을 제공한다. 데이터가 없으면 빈 축을 그리지 않는다.

### 공통 상태

| 상태 | 표시/동작 |
|---|---|
| 로딩 | 최종 영역과 같은 크기의 Skeleton, `aria-busy` |
| 검색 결과 없음 | “조건에 맞는 분석 상품이 없습니다. 필터를 줄이거나 다른 검색어를 입력하세요.” |
| 등록 상품 없음 | “현재 분석이 완료된 상품이 없습니다.” |
| 일부 정보 비공개 | 해당 값 `비공개`, 검증 불가능한 내용과 위험 반영 설명 |
| 원문 충돌 | 경고 callout, 충돌 값 2개 이상과 각 기준일, Evidence 열기 |
| API 오류 | 기존 목록/분석 유지 가능 시 유지, 오류와 재시도 |
| AI 실패 | 저장 최신 분석 → 규칙 기반 데모 → 명시 오류/재시도 |
| 이미지 없음 | 공통 placeholder와 작품명 alt/대체 텍스트 |
| 잘못된 URL | 404, 관련 목록 링크 |
| 데모 | 화면과 관련 카드/분석에 `데모 데이터` badge |

## 2. 글로벌 헤더·푸터·비교함

### 헤더

- 로고, 청약 상품, 작가, 플랫폼, 상품 비교 `{n}`, 분석 기준 순서.
- 모바일은 44×44px 이상 햄버거 → Drawer. ESC, focus trap, focus return을 제공한다.

### 비교함 `CompareTray`

- 상품 추가 시 화면 하단에 간결하게 표시한다. 상품명, 제거, 현재 개수/3, 비교하기를 제공한다.
- 동일 상품 중복 추가 금지. 3개에서 추가하면 기존 선택을 임의 제거하지 않고 제한 메시지를 표시한다.
- URL이 비교 상태의 정본이며 tray는 URL을 조작한다.

### 푸터

서비스 설명, 데이터 기준일, 분석 기준/출처 정책, 한 줄 면책을 표시한다.

## 3. 홈 `/`

### 목적

서비스 성격을 즉시 설명하고 자연어 검색 또는 한 번의 상품 클릭으로 분석을 시작하게 한다.

### 화면 순서와 데이터

1. **Hero**: 고정 문구, 고정 보조 문구, 자연어 검색 placeholder, `AI로 상품 찾기`
2. **빠른 진입**: 청약 예정/중, 해볼 만함/조건부/주의/위험
3. **청약 예정·진행 상품**: `ProductCard` 우선 정렬
4. **AI가 보는 네 가지**: 공모가/작가 시장/회수 가능성/플랫폼 이력 설명
5. **과거 완료 상품**: 청산 완료 일부와 실제기간
6. **서비스 원칙**: AI 조사·정량/정성·근거 연결

검색 제출은 `/products?q=...`로 이동한다. 빠른 진입은 해당 `status` 또는 `verdict` URL을 사용한다. 카드 내부의 상품/작가/플랫폼/비교 행동은 서로 겹치지 않는다.

### ASCII 와이어프레임

```text

│ LOGO  청약 상품  작가  플랫폼  상품 비교 2  분석 기준              │
├──────────────────────────────────────────────────────────────────────┤
│ 그림 조각투자,                                                      │

│ 공모가, 작가 경매 기록, 유사 작품 가격, 발행사 청산 이력…          │
│ ┌ 어떤 상품을 찾고 있나요? 예: 최근 거래가… ┐ [AI로 상품 찾기]    │
│ [청약 예정] [청약 중] [해볼 만함] [조건부] [주의] [위험]          │
├──────────────────────────────────────────────────────────────────────┤
│ 청약 예정·진행 상품                                                 │
│ ┌작품│상품/작가/플랫폼│판단+결론/근거│분석 보기│비교 추가┐ × N    │
├──────────────────────────────────────────────────────────────────────┤
│ AI가 보는 네 가지: [공모가] [작가 시장] [회수] [플랫폼 이력]      │

│ 과거 청산 완료 상품                 │ 서비스 원칙                   │
└──────────────────────────────────────────────────────────────────────┘
```

## 4. 상품 목록 `/products`

### 목적

자연어와 명시 필터를 결합해 상품을 찾고, 판단 근거를 짧게 비교한 뒤 상세/비교로 이동한다.

### 화면 순서

1. Breadcrumb, 제목
2. `NaturalLanguageSearch`
3. `SearchConditionChips`, 초기화
4. 결과 수, 정렬 select
5. FilterPanel(데스크톱) / 필터 Drawer(태블릿·모바일)
6. ProductCard grid/list
7. 페이지 이동

### 표시/동작

- 필터: 상태 5종, 판단 4종, 작가, 플랫폼, 최소 투자금, 공모가 차이율.
- 정렬: 마감 임박, 최근 등록, 판단, 공모가 차이 높은, 작가 거래량, 플랫폼 지연률.
- 카드: 작품 이미지, 상품 상태, 상품·작가·플랫폼, 최소 투자금, 총 공모금액, 취득가, 차이율, 판단, 한 문장, 핵심 근거, 분석/비교.
- 필터·칩·정렬·페이지 변경은 query를 업데이트한다. 칩 제거와 전체 초기화도 URL에 즉시 반영한다.

```text
┌ Breadcrumb / 청약 상품                         결과 4개 [정렬 ▾] ┐
│ ┌ 자연어 검색__________________________________ ┐ [AI로 찾기]   │
│ [청약 중 ×] [최근 3년 거래 많음 ×] [모두 초기화]               │
├──────────────┬───────────────────────────────────────────────────┤
│ FILTER       │ ┌──────── ProductCard ────────┐ ┌─────────────┐ │
│ □ 청약 예정  │ │ 이미지 │ 상태·판단           │ │ ...         │ │
│ □ 청약 중    │ │ 상품 / 작가 / 플랫폼         │ │             │ │
│ 판단         │ │ 금액·취득가·차이율            │ │             │ │
│ 작가/플랫폼  │ │ 결론·근거 / 상세 / 비교       │ │             │ │
│ 금액/차이율  │ └───────────────────────────────┘ └─────────────┘ │
└──────────────┴───────────────────────────────────────────────────┘
```

모바일에서는 결과 수 옆 `필터` 버튼으로 Bottom Sheet/Drawer를 열고 카드가 단일열이 된다.

## 5. 상품 상세 `/products/[productId]`

### 공통 헤더

Breadcrumb, 작품 이미지, 작품명/작가 링크, 제작연도·재료·크기·에디션, 법적 발행사, 플랫폼 링크, 청약기간, 총 공모금액, 최소 투자금, 상태, 데이터 기준일, 데모 badge, 비교 추가를 표시한다. 발행사와 플랫폼을 같은 행/필드로 합치지 않는다.

```text
┌ Breadcrumb: 상품 > DEMO 작품 01                                      ┐
│ ┌ 작품 이미지 ┐  작품명 / 작가↗          [데모 데이터] [비교 추가] │
│ │             │  연도 · 재료 · 크기 · 에디션                       │
│ └─────────────┘  발행사: ... / 플랫폼: ...↗ / 청약기간 / 공모금액 │
├ [요약] [공모가] [유사 작품] [작가 기록] [회수] [플랫폼] [근거] ─┤
│ 선택 탭 콘텐츠                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

탭은 `?tab=` Link로 변경하고 모바일에서 가로 스크롤한다.

### 5.1 요약 탭

순서: 최종 판단 → 한 문장 결론 → 이유 3개 → 3~5문장 종합 설명 → 네 축 결론/탭 버튼 → `AI에게 묻기`.

```text
┌ AI 청약 판단 ────────────────────────────────────────────────────┐
│ [주의 !] 가격보다 회수 과정의 불확실성이 더 큽니다.             │
│ [이유 1 수치+의미] [이유 2] [이유 3]                            │
│ AI 종합 설명 3~5문장                                             │
├ 공모가격 ─ [공모가 보기] ─┬ 작가 시장 ─ [기록 보기] ───────────┤
├ 회수 가능성 [회수 보기] ──┼ 플랫폼 이력 [이력 보기] ───────────┤
│ AI에게 묻기: [예시 질문] [입력________________] [질문]           │
└───────────────────────────────────────────────────────────────────┘
```

AI 질문 답변마다 Evidence 링크를 button으로 제공하며 열면 Drawer가 나타난다.

### 5.2 공모가 탭

Metric: 취득가, 감정가, 공모금액, 공개 비용 합계, 미설명 차액, 차이율, 유사 중위값, 중위값 대비 차이.

그래프 순서:
1. `PriceBridgeChart`: 취득가 vs 공모금액
2. `OfferingBreakdownChart`: 취득가+발행비+수수료+보관+보험+관리+기타+미설명
3. 설명 금액 vs 미설명 차액 강조
4. 유사작 가격 범위 위 현재 공모금액 위치
5. AI 인사이트와 근거 버튼

취득가 `null`이면 감정가로 바꾸지 않고 계산 불가/비공개 위험 문구를 표시한다.

### 5.3 유사 작품 탭

- 선정 기준 토글/설명: 동일 작가, 시리즈, 재료, 크기, 제작연도, 에디션, 거래시점, 상태, 국가·경매사.
- 산점도: x 거래일, y 낙찰가, 현재 공모 기준선, sold/unsold 모양, same series/medium/size를 패턴·라벨로 구분.
- 가격 범위 요약과 `ComparableSalesTable`.
- 표 열: 거래일, 경매사, 작품명, 연도, 재료, 크기, 추정가, 낙찰가, 결과, 유사성, 출처.
- 모바일 표는 가로 스크롤하고 첫 열을 과도하게 고정하지 않는다.

### 5.4 작가 기록 탭

차트: 5년 출품/낙찰 막대, 연도별 중위 낙찰가 선, 낙찰/유찰률, 시리즈·재료·크기 분포, 국가·경매사 편중. 그래프 뒤에 전체 거래와 동일 시리즈를 구분한 AI 설명을 둔다.

`작가 경력 보기` Disclosure 토글에는 전시·소장·수상·갤러리·공식 페이지를 넣는다. `aria-expanded`, 연결 panel ID를 사용하고 경력을 가격 상승의 직접 근거로 표현하지 않는다.

### 5.5 회수 분석 탭

- 연도별 거래 빈도와 유찰률 변화
- 유사 작품 재거래 목록
- 목표 보유기간 vs 과거 실제 보유기간
- 보유기간 연장 시 보관·보험 등 비용
- 매각 주체/의사결정/중도매각/수수료
- 매각 → 대금수령 → 배당 → 청산 타임라인
- AI는 단일 높음/낮음 gauge가 아니라 수치와 의미를 함께 표시한다.

### 5.6 플랫폼 이력 탭

Metric 12개: 전체 공모, 모집 완료, 운용 중, 매각 완료, 청산 완료, 기간 내 청산, 지연 청산, 미매각, 손실 확인, 평균 목표/실제 보유기간, 평균 지연.

차트: 상태 분포, 기간 내/지연 청산, 목표/실제기간, 상품별 배당·매각·청산 timeline. 표는 상품명, 작품, 작가, 공모금액, 목표/실제기간, 총 배당, 매각금액, 최종 상태, 지연을 제공한다.

### 5.7 근거 탭과 Drawer

기본은 접힌 `EvidenceAccordion` 목록이다. 제목은 분석 주장, 요약은 사용한 값/출처 유형이다. 펼치면 문서명, 발행 주체, URL, 기준일, 수집일, 계산식, 표본, 변경 이력, 충돌을 표시한다.

```text
┌ 근거: “공개 비용을 제외한 차액은 1,800만원”              [닫기 ×] ┐
│ 사용한 값 / 계산식 / 기준일                                         │
│ 원문 A: 문서명 · 발행 주체 · 기준일                    [새 탭 ↗]   │
│ 자료 충돌                                                            │
│   원문 A 120,000,000원 YYYY-MM-DD                                   │
│   원문 B 135,000,000원 YYYY-MM-DD                                   │
│ 변경 이력                                                            │
└───────────────────────────────────────────────────────────────────────┘
```

Drawer는 modal semantics, focus trap, ESC, 배경 닫기, 스크롤 잠금, focus 복귀를 지원한다.

## 6. 작가 목록 `/artists`

목적: 작가 전체 시장의 지속성과 관련 청약을 탐색한다. 작가명 검색, 최근 거래량/낙찰률/최근 거래일/관련 상품 수 정렬을 제공한다.

카드: 대표 이미지, 한/영문명, 최근 3년 출품, 낙찰률, 최근 거래일, 중위 낙찰가, 관련 상품 수, AI 한 줄. 카드 제목/분석 보기는 상세로 연결한다.

```text
┌ 작가 찾기________________ [검색]        [최근 거래량순 ▾] ┐
│ ┌ 이미지 │ DEMO 작가 A / A Demo                         │
│ │        │ 3년 출품 42 · 낙찰률 81% · 최근 거래일 ...  │
│ │        │ AI: 거래량과 동일 시리즈 표본이 함께 유지…  │
│ └────────┴───────────────────────────────────────────────┘
└───────────────────────────────────────────────────────────┘
```

## 7. 작가 상세 `/artists/[artistId]`

순서: Breadcrumb/기본정보 → AI 시장 분석 → 3/5년 거래 → 낙찰/유찰 → 가격 추이 → 시리즈/재료/크기 → 최근 거래 → 재거래 → 경력 토글 → 관련 상품 → 출처.

모든 관련 상품은 상품 상세로 연결한다. 작가 전체와 공모작과 같은 시리즈의 수치를 나란히 표시한다.

## 8. 플랫폼 목록 `/platforms`

카드: 플랫폼명, 운영사, 법적 발행사(복수 가능), 분석 상품, 운용 중, 매각 완료, 청산 완료, 지연 청산, 평균 실제 보유기간, AI 한 줄. 카드 선택은 상세로 이동한다.

## 9. 플랫폼 상세 `/platforms/[platformId]`

순서: 기본정보 → 운영사/법적 발행사 관계 → AI 분석 → 전체/상태 지표 → 목표/실제기간 → 배당 → 지연·미매각·손실 → 과거 상품 → 현재 관련 청약 → 근거. 동일 주체로 출처 확인된 경우에만 동일하다고 표시한다.

## 10. 비교 `/compare`

### 목적/동작

2~3개 상품을 동일 기준으로 비교한다. 0개면 상품 선택 CTA, 1개면 하나 더 선택, 2~3개면 AI 비교 결론과 표를 표시한다. 상품 제거·추가는 URL `ids`를 갱신한다.

```text
┌ 상품 비교 2/3                         [+ 상품 선택]          ┐
│ AI 비교 결론: 공개 자료 기준 A가 상대적으로 해볼 만함…      │
├ 비교 항목────────┬ A 상품──────────┬ B 상품──────────┬ C ───┤
│ AI 최종 판단     │ 조건부          │ 주의            │      │
│ 공모/취득/감정가 │ ...             │ ...             │      │
│ 차이율/미설명    │ ...             │ ...             │      │
│ 작가 거래/낙찰률 │ ...             │ ...             │      │
│ 동일 시리즈      │ ...             │ ...             │      │
│ 회수/청산/기간   │ ...             │ ...             │      │
└──────────────────┴─────────────────┴─────────────────┴──────┘
```

모바일 비교표는 가로 스크롤하고 각 상품명을 상세 Link로 유지한다.

## 11. 분석 기준 `/methodology`

목적: 숨은 점수 없이 판단 기준을 사용자가 검증하게 한다. 네 분석축, 가격/미설명 차액 공식, 유사작, 거래량·낙찰률 기간, 회수, 플랫폼 집계, 네 판단, 결측/충돌, 출처 우선순위, 갱신, `art-mvp-v1.0`, 한계와 면책을 Accordion/section으로 표시한다.

## 12. 반응형 명세

| 폭 | 처리 |
|---|---|
| 1440 | 본문 max width, 상품 헤더/판단 2열, 차트 2열 가능, 고정/측면 필터 |
| 1024 | 2열 축소 또는 분석 1열 전환, nav 간격 축소 |
| 768 | 필터 Drawer, 카드 1~2열, 표 가로 스크롤 |
| 390 | 단일열, 햄버거 Drawer, 탭 가로 스크롤, 차트 단일열, 44px touch |

텍스트는 확대 200%에서도 기능을 잃지 않아야 한다. 차트 container는 `min-width: 0`, 표 wrapper는 `overflow-x: auto`를 사용한다. 중요한 행동을 hover에만 숨기지 않는다.

## 13. 구현 컴포넌트 매핑

- Server: 페이지 shell, Repository 조회, metadata, 404, 초기 탭/URL 필터 해석
- Client: `NaturalLanguageSearch`, chips, Filter Drawer, CompareTray, 탭 보조 상호작용, Evidence Drawer, AI 질문
- 차트: 현재 의존성에 chart library가 없으므로 MVP는 접근 가능한 HTML/CSS/SVG 컴포넌트로 구현하거나 검토된 라이브러리를 명시적으로 추가한다. Canvas만으로 텍스트 대체를 생략하지 않는다.
- 이미지는 Next `<Image>` 또는 검증된 placeholder를 사용하고 외부 host 설정 여부를 확인한다.
