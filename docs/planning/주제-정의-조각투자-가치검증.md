## 1. 한 줄 정의

**발행사가 공시한 것과 공공 데이터가 일치하는지 대조하는 독립 검증 레이어.**

우리는 실물을 **보여주지 않는다.** 발행사가 이미 보여준다(R4 확인 — 뱅카우는 축산물이력제 기반 개체 추적, 미술품 업체는 갤러리 실물 전시). 우리는 **보여준 것이 사실인지 대조한다.**

> R4 결론: *"발행사가 스스로 보여주는 정보는 이미 충분하다. 없는 것은 그것을 대조할 제3자다."*
> 반례가 이미 있다 — RealT는 점유 24건이라 보고했으나 독립검증 결과 14건이 공실이었고, Masterworks는 자체 감정가 사용을 SEC 서류에 자백했다.

## 2. 검증 3층위 (재정의)

| 층위 | 검증 질문 | 대조 방법 | 데이터 |
|---|---|---|---|
| **① 실재성** | 신고서에 적힌 그 자산이 실제로 있는가 | 개체 이력번호 대조 | 축산물이력제 (mtrace.go.kr) |
| **② 가격 적정성** | 공모가·매각가가 시장 대비 어디쯤인가 | 실거래 백분위 | 국토부 실거래가 / 축평원 경락가 / K-ARTMARKET |
| **③ 이행·조건** | 약속을 지켰나, 불리한 조건이 숨어 있나 | 공시 이력 집계 + 문서 조항 추출 | DART 전수 + 플랫폼 공시 |

v1의 3층위(가격/이행/설명)에서 **①실재성이 신설**됐다. R3이 발견한 축산물이력제 대조 가능성 때문이며, 이것이 가장 강력한 검증 시나리오다.

## 3. 아키텍처 — 공통 엔진 + 자산군 어댑터

두 축(축산·부동산)을 동시에 하되 분량이 2배가 되지 않게:

```
[공시 문서]
   ↓ LLM 구조화 추출 — 검증 가능한 주장(claim) 단위로
[claim 목록]  예: "학산 12호 = 이력번호 002-XXXX" / "공모가 40억"
   ↓ claim 종류별 라우팅
[대조 어댑터]  축산물이력제 · 국토부 실거래가 · 축평원 경락가 · DART 전수
   ↓
[판정: 일치 / 불일치 / 확인 불가]  + 근거 카드(원본 좌표 + 대조 출처)
   ↓ 신뢰 스파인 출력 필터
[화면]
```

**자산군을 늘려도 늘어나는 건 어댑터 하나뿐이다.** 추출·판정·근거 카드·출력 필터는 공용이다.
이전 주제(약관)의 등급 불변식 설계 — *근거 0건이면 판정 없음* — 를 그대로 이식한다.

## 5. 데모 시나리오 (둘 다 동등 — 사용자 결정)

### 축 A — 한우 9호 라이브 검증 ★

**㈜스탁키퍼 가축투자계약증권 제9호** · `rcpNo=20260806000159`
**청약 2026-08-27 10:00 ~ 09-10 16:00** — 제출 마감(9/7 10:00)과 심사 접속 기간(9/7~9/11)에 걸쳐 **청약이 진행 중**이다.

- 공모총액 363,320,000원 / 20,000원 × 18,166주 / 한우 37두(학산 1호~37호)
- 사육농가 학산농장 — 약 700㎡, 축산경력 18년, 1++ 출현율 57.1%
- 자금용도: 취득비 218,339,377원 / 사료비 151,733,437원(두당 4,100,904원)
- **검증 포인트**: 37두 이력번호 ↔ 축산물이력제 실재 대조 / 두당 사료비·취득비 ↔ 경락가 대조 / 8-2호 청약 미달·자기인수 이력

⚠️ **8/6 제출 신고서다. 정정신고서로 일정이 바뀔 수 있다 — 주 1회 모니터링 필수.**

### 축 B — 부동산 사후 검증

**카사 공모 10개 건물** 지번 주소·공모금액·상장일·매각일 전량 확보(전부 매각 완료, 누적 공모 592.2억). 예: 서초 지웰타워(서초구 서초동 1678-4) 공모 40억 → **2026-03-11 매각 45.5억**.

- **검증 포인트**: 공모가·매각가 ↔ 국토부 실거래가 백분위. "그때 그 가격이 적정했는가"를 사후 판정
- 비브릭 2건(부산) 주소도 확보

**프레이밍**: 카사는 8/10 종료다. 이걸 약점이 아니라 **논거**로 쓴다 — *"1세대가 왜 무너졌는지 데이터로 보여준다."*

### 보조 — 핀돈 공시 이행 검증

데이터젠은 3호 기초자산에 폐사 수시공시 4건(7/20·7/22·7/27·8/3)과 월간 사육보고서(8/5)를 게시 중이다. **공시 이행 여부 자체**를 검증 대상으로 쓸 수 있다.

## 6. 표현 원칙 (v1에서 유지·강화)

- **"적정하지 않다"고 단정하지 않는다.** 백분위 **위치 제시**로 한정
- 판정은 **일치 / 불일치 / 확인 불가** 3값. "확인 불가"를 숨기지 않는다
- 모든 수치에 원천 출처 병기 — "이 백분위는 이 실거래 n건", "이 이력번호는 이 공시 p쪽"
- 신뢰 스파인 출력 필터로 단정 표현을 코드 레벨에서 차단
- **과장 금지 (R1)**: 폐업 ≠ 원금 소실. 신탁 구조상 기초자산은 남고 매각 대금이 분배된다. 카사는 +26%, 서초 지웰타워 +25%(세전)도 냈다. **"못 판다"는 참이지만 "돈을 떼인다"는 확인되지 않았다** — 이 구분을 흐리면 우리가 과장 마케팅이 된다

## 7. 시장 근거 (기획서 배경)

**핵심 논거 — 규제당국이 열흘 전에 우리 문제를 공식 인정했다.**

2026-07-28 시행 자본시장법 시행령 개정: 소액공모 한도를 10억→30억으로 확대하면서 **조각투자증권만 특례에서 배제**해 공모금액과 무관하게 증권신고서 제출을 의무화했다. 금융위가 밝힌 이유가 **"기초자산 가치평가와 투자위험을 충실히 알리기 위한 조치"**다.

보조 논거: 장외거래소 4분기~2027초 개설 예정 / 분기별 신탁재산 공시 의무화 / 2027-02-04 토큰증권 제도 시행

**쓰면 안 되는 논거**: "은행권이 조각투자에 집중한다" — 공개 기록은 오히려 반대다. 장외거래소 예비인가 주주에 은행 본체 0곳, 금융위 토큰증권 협의체 참여기관에 은행·은행연합회 없음.

## 10. 보류 결정

**"지분만큼 색칠해 완성" 게이미피케이션 — 보류.** (사용자 결정)

선례는 국내외 23개 플랫폼 중 0곳으로 신규성은 확실하나, **2026-04 시행 금융위 다크패턴 가이드라인의 ⑬감각조작** 유형 해석 리스크가 있다(영국 FCA 실험: 경품형 → 거래빈도 +12%, 18-34세 집중 / 매사추세츠 Robinhood $7.5M 합의). D-30에 규제 해석이 필요한 기능을 넣는 비용이 크고, 심사 어젠다(보안·검증)와도 정합성이 낮다.

→ **기획서의 확장 로드맵에 서술만 한다.** 구현 시에는 "보유 지분 유지"가 아니라 "납입 지속"에 연동해야 한다(매도 억제 장치 해석 회피).
