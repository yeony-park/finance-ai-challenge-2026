## 1. 조각투자 플랫폼 실태 (뱅카우·아트앤가이드·아트투게더·테사·카사·펀블·소유·피스)

### 업계 공통 패턴

- **첫 화면 공식 = 최소금액 + 일상어 비유**: 5천원(펀블·소유)·1천원(테사), 개념 설명은
  주식("주식처럼 매매", 카사)·쇼핑(펀블)·월세("월세처럼 지급되는 배당금", 소유) 멘탈모델 차용.
- **라이프사이클 상태 머신 사실상 표준화**: 공모/청약(선착순 or 비례) → 배정·납입 → 상장/보유 →
  배당(부동산)·성장 소식(한우)·보관(미술품) → 매각 총회 → 매각·정산. 카사는 시간대까지 명시
  (공모 09~22시, 거래 09~17시). 카테고리 차이는 '보유' 단계 콘텐츠뿐 — 상태 배지는 전 카테고리
  공통 하위 계층으로 추상화 가능.
- **신뢰 신호 = 기관 이름 나열**: 혁신금융서비스 지정, 계좌관리기관(증권사·은행), 신탁사,
  예탁결제원, 감정평가법인 2곳. 위치는 푸터 + 상품 상세 하단.
- **위험 고지 3종 정형문은 전부 하단 배치**: 원금손실 가능 / 예금자보호 비대상 / 과거 수익률
  미래 미보장. 메인 상단에 위험을 노출하는 곳은 없음.
- **투자계약증권 규제 UX 4종**(금감원 요구라 어디든 존재): 청약 전 적합성 테스트, 증권신고서
  DART 링크, 발행인 10% 선배정 표기, 운영기간·미매각 절차 사전 공시.
- **웹은 껍데기, 실거래는 앱**: 전 서비스 웹이 SPA 마케팅 랜딩(해외 IP 차단·JS 없이는 본문 없음).
  **웹에서 공시 정보를 제대로 보여주는 것 자체가 업계 최대 공백** — 발행 플랫폼들은 증권신고서를
  "DART 가서 보세요" 수준으로 처리.

## 2. 입문자 UX 라이팅·카드 문법 (토스·카카오뱅크·뱅크샐러드)

- **토스증권 3요소 원칙**: 종목 카드에 이름·현재가·오늘 변화 3가지만, 나머지는 진입 후 점진 공개.
  첫 행동을 "투자"가 아닌 **"탐색"**(잘못해도 잃는 게 없는 행동)으로 설계. 기본 차트는 캔들이
  아닌 단순 선.
- **언어 변환 관례**: "매수/매도"→"구매하기/판매하기", "2.34% 하락"→"2,300원 내렸어요".
  숫자마다 설명조 캡션 한 줄("이 종목을 보유한 사람들의 평균 수익률이에요").
- **토스 라이팅 8원칙**: 해요체 통일·능동형·긍정형, 문구를 디자인 시스템 컴포넌트에 내장해
  40여 서비스 보이스톤 자동 통일. 신뢰의 원천은 다정함이 아니라 **문체의 일관성**.
- **카카오뱅크 상품 카드**: 슬로건 1개 + 요약 3가지. "만기 예상액" 사전 제시로 사용자의 계산
  부담 자체를 제거.
- 출처: 토스피드 UX Writer 인터뷰 · brunch 토스증권 분석 · pxd Story(카카오뱅크).

**적용점**: 판정어 "대조 불가"는 입문자에게 실패로 읽힐 위험 — easy 눈높이에서
"비교할 원본 자료가 아직 없어요" 류 병기 캡션을 **디자인 시스템 수준에서 고정**
(문안은 `content/` 모듈 + 필터 감사 경로).

## 3. 검증·근거 UI (팩트체크·AI 인용·문서 미학)

- **SNU팩트체크**: "판단유보" 라벨을 1급 시민으로 운용 + 근거 자료를 직접 접근 링크로 공개.
  기사당 근거 수(0.45→4.36개)가 품질 지표로 통용 — "대조 불가" 정직 표기·근거 카운트 노출이
  국제 팩트체크 관례와 일치함을 확인.
- **주의(강함)**: PolitiFact류 **판정 미터/게이지 은유 금지** — JeomJeom 판정은 정도(degree)가
  아닌 종류(kind)의 구분. 이산적 스탬프 은유 유지(04 집계 점수 금지와도 정합).
- **AI 인용 UI 패턴** (AYDesign 2026 정리): 문장 단위 인용 부착(문단 아님), **원문 구절 딥링크 +
  해당 구절 하이라이트**("1분 검증을 2초로"), 근거 강도 배지, 미출처 주장 명시적 표시,
  답변 후 "어떻게 대조했는지" 토글(Audit Trail — 펼치지 않아도 존재가 신뢰 신호).
- **문서 미학**: 모노스페이스=시스템·기계 대조의 신호(메타데이터 한정), 본문은 부드러운 본문체 —
  현행 `--ds-font-mono` 관례와 동일. edgar.tools는 "패러프레이즈 아닌 제출된 그대로의 공시
  문언 + 전 숫자 원 공시 인용"을 셀링 포인트로 삼음. DART 뷰어의 가독성 공백이 곧 기회(§1과 수렴).
- **노랑 하이라이트 의미 고정 제안**: "원문에서 대조한 구절" 형광펜 은유로 기능화(장식 아님).

## 4. AI 검색·온보딩·차트

- **예시 질문 칩 = 판단 기준 커리큘럼**: 입문자는 "뭘 물어야 하는지" 자체를 모름 — 칩이
  확인 질문을 가르치는 교육 도구(IDI ★★와 동일 구도). Perplexity 실측: **답변 후 후속 질문 칩이
  초기 칩보다 강력**(참여 2배). "이거 사도 돼요?" 류에는 모드 분리로 기대치 재설정.
- **온보딩**: 위험 성향 설문은 회피(설문 존재 자체가 "추천받는다" 오해 유발 — 로보어드바이저
  180문항 연구의 고질병=불투명 프로파일링). **"왜 위에 올렸는지" 배지**(explainable
  personalization — Shaped.ai·New America)가 현행 선언형 정렬·숨김 금지 원칙의 완성형.
  "건너뛰어도 전체가 동일하게 보인다" 명시가 신뢰 자산.
- **차트 = 정부 통계(영국 ONS) 문법이 곧 브랜드**: 중립 종횡비·단일축·결측 구간 잇지 않기(현행
  잉크 도판 차트가 이미 준수)·범례 대신 선 끝 라벨·텍스트 대안. 국내 증권의 상승 빨강/하락 파랑
  관례는 **의도적 회피**(판정 3색의 의미 점유 보호 — "가격은 사실이지 신호가 아니다").
  차트 주석은 사건 사실만("2026-03-12 정정 접수") — 해석어(반등·저점) 금지. 캡션·출처 각주·모노
  축 라벨의 '도판 1' 미학으로 리포트와 통일.

## 5. 수정 후보 (레퍼런스 → 현행 갭 매핑)

우선순위는 [입문자-여정.md](입문자-여정.md) 갭과 레퍼런스 근거가 겹치는 순. 일정 배정 없음.

**A. 여정 갭 직결 (문서상 확인된 미구현)**

- **A1. 확인 질문 → 리포트 챕터 다리** (여정 4단계 갭): 체크리스트 각 항목에 "이 공모에서
  확인하기" → `ReportChapterNav` 앵커 딥링크. 근거: AI 인용 패턴의 원문 딥링크, edgar.tools.
  여정 문서가 "가장 값싼 고효율 갭"으로 지목.
- **A2. 재방문 정정 감시 홈 표면화** (여정 5단계 갭): watchlist 공모의 정정 유무를 홈 첫 화면에.
  근거: 카사의 공시 피드 상설 운영(업계 유일), 뱅카우 소식 피드.

**B. 문안·어휘 (코드 소규모, 필터 감사 경로)**

- **B1. 판정어 easy 병기 캡션**: 3판정 각각에 설명조 한 줄을 디자인 시스템 어휘로 고정
  ("원장 불일치" 옆 "공시에 적힌 내용과 원장 기록이 달라요" 류). 근거: 토스증권 언어 변환,
  SNU팩트체크 판단유보.
- **B2. 후속 질문 칩**: 대화 모듈·리포트 하단에 맥락 후속 칩(정적 매처 범위 내).
  근거: Perplexity 참여 2배 실측.
- **B3. 정렬 이유 배지**: concern·interests로 재정렬된 항목에 "내 걱정/관심이라 위로 올렸어요"
  표기(현행 "내 걱정" 태그의 일반화). 근거: explainable personalization.

**C. 구조 확장 (엔진·데이터 접점, 규모 중)**

- **C1. 라이프사이클 상태 배지 공통화**: 청약예정/청약중/마감/보유/매각 상태 머신을 카드·리포트
  공통 컴포넌트로(현행 청약 배지의 일반화). 카테고리 차이는 '보유' 단계 콘텐츠 슬롯만.
  근거: 업계 표준 상태 머신, 01 카테고리 계약과 정합.
- **C2. 증권신고서 핵심 항목 구조화 노출**: 발행인 선배정 비율·운영기간·미매각 절차·평가기관 수 —
  업계가 "DART 가서 보세요"로 방치한 최대 공백. 파싱·claim 확장이 필요해 엔진 접점
  (`parse/`·`claims/`) 선행 검토 필요.

**D. 규제 검토 선행 (바로 착수 금지)**

- **D1. 노랑 하이라이트 의미 고정**: "대조한 원문 구절" 형광펜 기능화 — 기존 `.mark` 용례 전수
  감사 후 적용(의미 충돌 시 혼란이 더 큼).
- **D2. 절대금액 표기**: 소유 반례(월 2천원 기대관리 실패)의 교훈이나, 수익 시뮬레이션은
  참여 촉구·판단 유도 경계(04 participation-push) 침범 위험 — 표현 규칙 검토 선행.
- **D3. "어떻게 대조했는지" 토글**: 리포트에 방법 요약 접이식 — `/methodology` 요약의 인라인화.
  자기보고형 판별 기준(주어=서비스) 통과 문안으로만.

## 6. 현행 유지 확인 (레퍼런스가 역으로 검증해준 것)

- 공모 카드 그리드(947e9ee) = 토스증권 3요소 문법과 일치.
- 잉크 도판 차트(1147dad) = ONS 문법(결측 단선·중립 표기) 기준 이미 준수.
