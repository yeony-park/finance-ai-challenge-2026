## 0. 결론 요약

재구조화안은 **UX 계층과 문서 규율은 탁월하지만, 공모전 맥락에서 두 가지 치명 문제**가 있다:

1. **경쟁 프레임을 "경쟁자 0인 시장"에서 "프랩과 정면 경쟁하는 시장"으로 옮긴다.** 검증 리포트의 직접 경쟁자는 국내외 0곳(글로벌 공백, 8/10 마켓 리서치 확인). 카탈로그·검색의 직접 경쟁자는 프랩(21개 플랫폼 2만 상품 집계— 8/10 실측 확인)이다.
2. **킬러 자산을 폐기한다.** 자산군이 부동산·미술품·항공기 엔진으로 바뀌면서 한우(뱅카우 9호)가 사라진다 — 실측 36/37 일치·1두 불일치 발견 + 심사 기간(9/7~9/11)과 겹치는 라이브 청약(8/27~9/10)이라는, council 3차에서 3인이 독립 수렴한 "③④⑤를 동시에 떠받치는 단일 핵심 자산"이다.

**권고: 방향 대결이 아니라 흡수.** 검증 코어(3층위 대조·판정·근거 카드)와 자산군(한우+부동산)을 유지하고, 재구조화안의 정보 구조(검색→카드→상세→근거 단계 공개)와 트랙레코드 제품화를 **검증 리포트의 포장 계층**으로 수용한다. 미술품·항공기 엔진·자연어 검색·검토 상태는 기획서 ⑥ 로드맵으로 이동.

## 1. 차별성 분석 — 같은 회사, 두 개의 경쟁 지형

### 포지셔닝 브리프 대조

| 축 | A. 기존 PRD (공시 대조 검증) | B. 재구조화안 (DAKER 카탈로그) |
|---|---|---|
| 정체성 | 신고서 주장을 공공데이터로 **심문**하는 제3자 검증 | 상품을 찾고 조건을 확인하는 **검토 카탈로그** |
| 오퍼 | 3층위 대조(실재성·가격·이행) → 판정 3값 + 근거 카드 | 자연어 검색 + 조건 카드 + 검토 상태 + 트랙레코드 + AI 코멘트 |
| 타깃 | 청약 검토 투자자 (트리거: 신규 공모) | 신규 시장 참여자(탐색) + 기존 투자자 |
| 차별 논거 | 제3자 검증 0곳·글로벌 공백 + 실측 불일치 발견 | 근거 기반 검토 상태 + 트랙레코드 |
| 전략적 긴장 | 신뢰성(단정 금지) × 임팩트(불일치 발견) | 접근성(짧은 화면) × 근거 깊이(단계 공개) |

### 경쟁 티어링 — 프레임 A (검증)

| 티어 | 플레이어 | 판정 |
|---|---|---|
| Direct | **없음** — 혁신금융 1,112건 중 제3자 검증 지정 0건, 비유동 실물자산 공시↔공공데이터 상시 대조는 해외에도 부재 (8/10 마켓 리서치) | 백지 시장 |
| Adjacent | 더벨(신고서 수기 대조 — 자동화·상시화 안 됨), 프랩(집계·비교 — 검증 기능 미보유 실측 확인), Outlier Media(RealT 폭로 — 저널리즘 1회성) | 수작업·비상시 대체재만 존재 |
| Aspirational | Chainlink PoR·Chronicle(유동자산 전용), ESG 어슈어런스 산업(CSRD 이후 분화 선례) | "검증 레이어 분화"의 선행 궤적 |

→ 차별성 서술이 자명하다: **"숫자를 나란히 놓는 서비스는 있어도 심문하는 서비스는 최초."**

### 경쟁 티어링 — 프레임 B (카탈로그·검색)

| 티어 | 플레이어 | 판정 |
|---|---|---|
| Direct | **프랩(prap.kr)** — 21개 플랫폼 약 2만 상품 집계·비교·수익률·양수도 중개 (8/10 실측). 재구조화안의 검색·카드·조건 비교와 정면 겹침 | 선발 사업자 존재 |
| Direct | 각 플랫폼 자체 상품 목록(카사·소유·펀블·테사·열매 등) — 자기 상품에 한정되나 데이터 원천 보유 | 데이터 접근성 열위 |
| Adjacent | KIND/DART(원문 공시), 증권사 앱, 금융상품 비교 서비스류 | 부분 겹침 |
| Aspirational | Morningstar(펀드 평가·등급), Carfax(이력 리포트) | 카탈로그+평가 결합의 종착점 |

→ 우리는 **후발 카탈로그**가 된다. 남는 차별 요소는 "검토 상태·트랙레코드·근거"인데, 재구조화안 스스로 **검토 상태는 표본·민감도·법률 검토 완료 전 비활성(`-`)**이라 규정한다. 즉 9/7 심사 시점의 데모에서 차별 기능이 꺼진 채 검색과 카드만 보일 가능성이 높다 — 심사자 눈에는 "프랩의 축소판"이다.

### 규모 사실 하나가 검색 중심 설계를 흔든다

검증 대상인 투자계약증권은 **2026년 전수 8건, 2023~25년 포함 34건** (Phase 1 계획의 수집 목표). 부동산 수익증권을 더해도 수십 건 규모다. **수십 건 카탈로그에서 자연어 검색은 핵심 UX가 될 수 없다** — 검색이 가치를 갖는 프랩(2만 건)과 대상 규모가 다르다. 재구조화안의 검색 예시("서울에 있는 최소 투자금액이 낮은 부동산 상품")는 결과가 0~3건으로 수렴하는 질의다.

## 2. 재구조화안 상세 피드백

### 계승할 강점 (본진보다 정교한 부분)

1. **문서 규율** — [팩트]/[추론]/[제품 결정] 태깅, 출처·기준일 명시, 미확정 항목의 정직한 분리. 기획서 전사 시 이 규율을 그대로 쓰면 좋다.
2. **신뢰 스파인의 정교화** — 코멘트 내 `[확인된 사실]/[발행사 주장]/[계산]/[AI 해석]` 구분, 출처 등급 사다리, 값 충돌 시 병기 원칙, 근거 버전 재현성("같은 근거 버전 = 같은 결과"), 누락값 `-` 통일과 "공개 자료에서 확인되지 않음" 문구. **본진 PRD의 단정 금지 원칙을 오히려 더 구체화했다. 전부 수용 권장.**
3. **발행사 ≠ 브랜드 ≠ 플랫폼 분리** — 트랙레코드 왜곡 방지. 본진 ③이행 이력 층위 설계에 즉시 반영할 가치.
4. **완료/지연 분리, 연환산 수익률 제외, 자료 부족 ≠ 주의** — 오해 방지 설계 전부 타당.
5. **생애주기 예상값/실제값 분리** — 사후 검증(축 B)의 서술 구조로 유용.
6. **미술품 거래자료 해석 주의(K-ARTMARKET 한계, "공개 거래 기록 확인 불가" 표기)** — 정직성 원칙의 모범.

### 치명 문제 (공모전 맥락)

1. **자산군 교체 = 킬러 자산 폐기.** 한우가 빠지면 (a) 실측 36/37·1두 불일치 발견, (b) 심사 기간과 겹치는 라이브 청약, (c) 축산물이력제 API 실호출 검증 완료라는 3중 자산이 사라진다. 대체로 들어온 미술품은 문서 스스로 인정하듯 보편 공개 등록부가 없어 "가격 검증 불가" 폴백이 잦을 자산군이고(본진이 음악저작권을 제외한 것과 같은 이유의 약한 버전), 항공기 엔진은 "공개자료 확보 가능 범위 미확정" — **죽는 조건을 판별하지 않은 신규 자산군 2개로, 판별 완료된 자산군 1개를 대체하는 교환**이다. Phase 0 게이트 원칙(죽는 조건 선판별) 위반.
2. **공모전 부재.** 문서 전체에 9/7 마감·심사 기준·MVP 제출이 등장하지 않는다. "임의 완료일을 부여하지 않는다"는 규율은 평시엔 옳지만 지금은 마감이 실존한다. 자연어 검색 + 3자산군 수집 파이프라인 + 트랙레코드 집계 + 기준 버전 관리는 Phase 3 실질 6일(Pragmatist 실측)로 불가능한 범위다.
3. **검토 상태의 자기모순적 타이밍.** "표본·민감도·법률 검토 전 비활성"은 신중함으로는 옳으나, 그 결과 심사 시점 데모에서 검토 상태가 전부 `-`가 된다. 차별 기능이 심사에 보이지 않는 설계.
4. **크롤링 리스크 재도입.** "플랫폼 공식 웹페이지 수집·파싱"은 본진이 8/8 주제 전환으로 제거했던 크롤링 회색지대(robots·TDM)를 되살린다. 본진은 OpenDART 공시로 이 리스크를 우회했다.
5. **익명화 결정과 충돌.** 발행사 실명 트랙레코드(서울옥션·소유 등 예시)는 본진의 "익명화 기본, 실명 전환은 팀 결정 전 없음"(8/10 확정)과 정면 충돌. Critic이 지적한 스폰서 법무 리스크 관점에서도 실명 트랙레코드가 더 위험하다.
6. **판정 체계 이원화.** 재구조화안 "양호/주의/-"(조건의 고정 기준 충족 여부)와 본진 "일치/불일치/확인 불가"(공시 주장의 사실 대조)는 의미가 다른 판정이다. 병존하면 사용자·심사자 모두 혼란 — 하나를 선택해야 하며, 공모전 임팩트는 사실 대조 쪽에 있다("발행사 주장이 원장과 다르다"는 발견 가능, "조건이 기준 미달"은 발견 서사 없음).
7. **문서 계보 단절.** 참조 문서(./PRD.md, ../PROJECT_STATUS.md, "부동산 3개·미술품 5개 기존 데이터")가 본 repo가 아닌 팀원의 별도 프로토타입 기준이다. 본진 8/10 확정 PRD·council 3차 평결·마켓 리서치와 동기화되지 않았다. "Fable 2차 검토 PASS"는 그 문서 내부 정합성에 대한 판정이지, 공모전 전략·본진 계획과의 정합성 검토가 아니다.

## 3. 방향성 재점검 — 흡수안

### 원칙

IDI가 포착한 사용자 요구(탐색 비용 절감, 짧은 검토, 트랙레코드)는 실재한다. 그러나 그 요구는 **검증 코어를 버려야 충족되는 게 아니라, 검증 결과를 담는 정보 구조로 충족된다.** 재구조화안의 `검색 → 카드 → 상세 → 근거` 계층은 본진의 `3초 판정 → 탭 단계 공개(프로그레시브 디스클로저)`와 구조적으로 동일하다 — 이름이 다를 뿐, 합칠 수 있다.

### 통합 매핑

| 재구조화안 요소 | 처리 | 근거 |
|---|---|---|
| 검색→카드→상세→근거 단계 공개 | ✅ **수용** — 본진 "3초 판정 첫 화면 + 탭 공개"의 구체 설계로 채택 | 구조 동일, IDI 검증됨 |
| 문서 규율·코멘트 태깅·출처 등급·충돌 병기 | ✅ **수용** — 신뢰 스파인에 병합 | 본진 원칙의 상위 호환 |
| 발행사/브랜드/플랫폼 분리 | ✅ **수용** — ③이행 이력 층위 설계에 반영 | 트랙레코드 왜곡 방지 |
| 발행사 트랙레코드 | ✅ **수용(개칭)** — 본진 Phase 2 "이행 이력 집계·발행사 단위 이력 카드"의 제품 명칭으로 | 이미 계획에 존재 |
| 예상값/실제값 분리 | ✅ **수용** — 축 B(카사 사후 검증) 서술 구조로 | 완료 상품 검증에 적합 |
| 상품 생애주기 필터 (모집 예정~완료) | ⚠️ **축소 수용** — 수십 건 규모에선 목록+상태 뱃지로 충분 | 규모 사실 |
| 자연어 검색 | ⚠️ **로드맵** — MVP는 공모 선택 UI(대상 수십 건). 기획서 ⑤에 "상품 폭 확대 시 자연어 검색" 서술 | 검색 대상 규모 부족 + Phase 3 6일 |
| 검토 상태 (양호/주의/-) | ⚠️ **로드맵** — MVP 판정은 일치/불일치/확인 불가 유지 | 판정 이원화 방지 + 공개 전 조건이 심사 일정과 양립 불가 |
| 미술품 자산군 | ⚠️ **로드맵** — 기획서 ⑥ 확장성 (K-ARTMARKET 한계 서술 포함) | 독립 대조 데이터 취약 |
| 항공기 엔진 자산군 | ⚠️ **로드맵** — 죽는 조건(공개자료 확보) 판별 후 | 문서 스스로 미검증 인정 |
| 플랫폼 웹 크롤링 수집 | ❌ **거부** — OpenDART 공시 경로 유지 | 법적 회색지대 재도입 |

| 한우 자산군 제외 | ❌ **거부** — 뱅카우 9호 라이브가 심사 전략의 축 | council 3차 3인 수렴 |

### 이 흡수안이 기획서 심사 항목에 주는 효과

- **③ 문제 정의·고객**: IDI 기반 사용자 요구(탐색·짧은 검토)를 고객 정의에 추가 — "가정"이 아닌 인터뷰 출처 명시 가능. 수요 Assumption 방어가 한 겹 두꺼워진다.
- **④ 차별성**: 프레임 A(경쟁자 0) 유지. 프랩과의 관계는 "집계 서비스 위에 없는 검증 레이어"로 서술 — 프랩의 존재가 오히려 시장 성숙 증거가 된다.
- **⑤ 생성형 AI**: 검색 조건 추출·코멘트 태깅 등 재구조화안의 AI 활용처를 로드맵으로 서술해 활용 폭 확장을 보여주되, MVP는 "환각이 판정에 닿지 않는 구조" 유지.

## 4. 팀 회의 안건 (권고)

1. 흡수안 합의 여부 — 특히 **한우 유지 + 미술품·항공기 엔진 로드맵 이동** (팀원의 IDI 성과를 부정하는 게 아니라 시점 문제임을 명확히)
2. 판정 체계 단일화 — 일치/불일치/확인 불가로 통일하는 데 합의
3. 팀원 프로토타입(부동산 3·미술품 5, 실사 대시보드)과 본진 repo의 관계 정리 — 어느 코드베이스로 수렴할지
4. 첫 화면 동선(council 3차 최우선 보강 1건)에 재구조화안의 카드→상세→근거 계층을 적용한 설계 확정
