## 안건 1 — 명세 번호 08 충돌 (user-flow 머지 전 필수)

- integration: `docs/spec/08-api-contract.md` (계약 — 규범). user-flow: `docs/spec/08-service-api.md` (현행 3종 문서화 — 기술서. 스스로 "구현과 충돌하면 구현 우선" 선언).

- **제안(기본값)**: user-flow 쪽을 `10-service-api.md`로 리넘버하고 서두에 "계약은 08 · 집행은 contracts/api.md, 본 문서는 현행 응답 실측 기술" 관계 명시. 머지 커밋에서 함께 처리.

## 안건 2 — 현석 AI 라우트 4종 vs `/api/search` 계약 통일

- 현석: `POST /api/ai/search`(자연어→검색조건 구조화) · `/ai/ask-product`(근거 문답) · `/ai/analyze-product`(요청 중 OpenDART ZIP 다운로드+LLM) · `/ai/compare`. OpenAI Responses API 직접 fetch(스파인 우회), 인메모리 레이트리밋, 에러 바디 형태 상이.
- integration 계약: AI 표면은 `POST /api/search` 단일 진입(08 §4) + 06 게이트 4종(레드팀·전역 한도·킬스위치·강등 리허설) 통과 전 비공개 + 캐시 전용 원칙(대화 중 라이브 원장 호출 금지).
- **제안(기본값)**: ① `/ai/search`의 "구조화" 단계는 `/api/search` 내부 1단계로 흡수(2단 파이프: 구조화→검색→인용) ② `ask-product`의 GroundingContext 연속성 모델(스냅샷 sha256 + 409 리셋)은 설계 보존 이식 ③ `analyze-product`의 요청 중 DART 호출은 사전 생성 파이프라인으로 이동(06 §3) ④ 화면이 안 쓰는 `GET /api/products|artists|platforms|methodology` 4종은 폐기. — 현석 확인 필요.

## 안건 3 — 미술품 "단일 범위" vs 4카테고리 균등 (제품 스코프)

- 현석 정본 `ART_INVESTMENT_PRODUCT_SPEC.md`는 "부동산·가축을 화면·필터·문구에서 제거"를 명시 + `app/art/page.tsx`를 카탈로그로 전면 교체 + 4단계 투자 판정(해볼 만함/조건부/주의/위험) 사용.
- 팀 기합의: 4카테고리 균등 + 판정은 사실 3값(일치/원장 불일치/대조 불가) 계열, 등급 판정 미채택.
- **제안(기본값)**: 카탈로그·비교 화면은 `/products`·`/compare` 신설로 이식하되 `/art` 착지 교체 금지, `CompareTray`는 art 세그먼트로 격리, 4단계 판정 필드는 이식에서 제외(판정 슬롯은 3값 리포트 연동으로 대체). — 현석 확인 필요.

## 안건 4 — ADR-0001 (MAFRA ASF 지도 iframe) 철회 또는 승격

- pig-review 브랜치가 "iframe 임베드 금지"(05 §3)를 개인 세션 근거("Current conversation, no durable link") ADR로 예외 처리하고 스펙 2곳을 되돌림.
- **제안(기본값)**: 현 integration 방식(정적 목록+외부 링크) 유지, ADR-0001은 팀 회의에서 승격 여부 결정. 승격 시에도 sandbox `allow-same-origin`+`allow-scripts` 동시 부여는 재작업 필요(sandbox 무력화).

## 안건 5 — 발행사 실명 표기 방침 (`allowedPublicNames`)

- 연정 원본은 발행사·농장·시군까지 실명. integration 게이트는 전부 중립화(누출 0건 회귀 테스트).
- DART 법정 공시 법인명은 05 §1상 허용 "후보"지만, 카테고리 디스크립터의 `allowedPublicNames` 선언 + 이의제기 채널 고지가 선행 조건.
- **제안(기본값)**: 발행사 법정명에 한해 선언 허용 검토(농장·공급사·시군은 계속 중립화), 고지 문안은 `src/lib/content/` 등재 + 출력 필터 감사 후. — 연정 확인 필요.

## 안건 6 — 미술품 데이터셋 라이선스 재판정 → **오너 확정 (2026-08-29): 반입 안 함**

- 현석 번들: `artnguide_due_diligence.json`(815KB)·`weshareart_research.json`(559KB) 등 1.8MB. 아트투게더는 Red 강등 권고 이력(6f9084d), 아트앤가이드·위셰어아트 수집 방식·약관 판정 기록 미확인.
- **오너 확정**: 실데이터 338건은 integration에 **반입하지 않는다** — 쟁점이 실명(익명화로 해소 가능)이 아니라 수집 적법성(라이선스 축)이라 익명화·파생 synthetic으로도 해소 불가. 미술품 구성 = **실측 공모 5건(DART 공시 유래, manual_verified·익명화) + 완전 synthetic 더미(결정적 생성기, `ex-` 프리픽스·예시 고지)**. 추후 서면 확인(05 §2)이 완료된 데이터셋에 한해 재론.
