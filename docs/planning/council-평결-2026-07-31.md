# Council: 팀 회의에 가져갈 후보 선별

> 2026-07-31. 4인 협의체(Architect=본 세션, Skeptic·Pragmatist·Critic=격리 서브에이전트). 원문 입장은 아래에 보존.

**Architect:** B·A·D를 가져가고 C는 공통 설계 원칙으로 강등, E는 타깃팅으로 B에 흡수.
— B는 어젠다 정면+공백+데이터 완비, C의 본질(가드레일)은 어느 주제에든 얹을 수 있어 기회비용이 없음.

**Skeptic:** C는 회의에 가져가지도 마라. B·A·E 확정, D는 보험 검증자를 확보할 때만. 회의 산출물을 '주제 토론'이 아니라 '후보별 데모 스파이크 계획'으로 재정의하라.
— 기관 어젠다와 심사 기준은 다르며, 경쟁 밀도는 탈락 사유가 아니라 요구 실행력의 눈높이. **후보는 상호배타가 아니다: B×E(시니어 피해자)·B×A(외국인 피해자) 재조합이 최저비용 차별화.**

**Pragmatist:** A·B·C를 가져가되 진짜 결정은 "C를 어디에 붙이나"다. D·E는 지금 컷.
— A·B·C만이 "공개 문서 RAG+API+멀티에이전트 하네스"로 5주 내 조립 가능. **C를 '가드레일+자체 레드팀 리포트 동봉' 모듈로 A/B에 흡수하면 금보원 어젠다가 B2B 리스크 없이 가점으로 변환.**

**Critic:** C·E를 지금 죽이고 A·B·D. 단 셋 다 "틀리면 사람이 다치는 정보 제공형"이라 실패 모드가 할루시네이션 하나로 상관됨 — 출처 강제+human-in-the-loop 체계를 5주에 세 번 만들 수 없다.
— C는 레드팀 운영 기관 앞 자살행위, E는 심사장 마이크 오인식 한 번에 끝. **9/7~9/11 무중단·동시접속·크레딧·레이트리밋·인젝션 방어에 지금 예산을 배정하라.**

## Verdict

- **Consensus (4/4)**: ① A·B는 확정 지참. ② **C는 단독 주제로 사망** — '신뢰 스파인' 공통 모듈(가드레일+자체 레드팀 리포트)로 전 후보에 내장. ③ E는 단독 사망, '시니어 타깃 변형(B×E)'으로 흡수. ④ 후보는 상호배타가 아니라 재조합 대상.
- **Strongest dissent**: D — Pragmatist "지금 컷"(도메인 습득 비용이 5주 잠식) vs Critic·Architect "지참". Skeptic의 중재를 채택: **명시적 생존 조건(보험 지식 검증자 확보) + 죽는 조건을 달아 조건부 지참.** 은행 현직자의 방카슈랑스 경험이 소생 변수.
- **Premise check (Skeptic)**: 질문 자체를 수정함 — 회의는 '주제 토론'이 아니라 '정보 수집(현직자 청취) → 후보 검증 → 스파이크 계획 확정'. 또한 Critic이 B의 전제('사후 대응 공백')에 재검증을 요구 — 금감원 원스톱·118 등 기존 체계 확인 항목으로 등재.
- **Recommendation**: 회의 패키지 = **B(타깃 변형 옵션 포함)·A·D(조건부) 원페이저 3장 + 신뢰 스파인 공통 모듈 1장 + 재정의된 회의 아젠다.** 주제 확정 시한 8/7(선정에 1주 이상 소모 금지). 신뢰 스파인은 주제 독립적이므로 확정 전에 개발 착수 가능.

### Architect 입장 변경 기록 (편향 가드)
- C '강등'은 Skeptic·Critic의 논거("심사자가 레드팀 운영 기관 — 어설픈 보안 데모는 마이너스 자산")로 '단독 사망'으로 강화됨.
- Critic의 운영 리스크(무중단·크레딧·인젝션)를 독립 워크스트림으로 승격 — 초기 입장에 없던 항목.
- D 지참은 유지하되 Skeptic 조건(검증자)과 Pragmatist 반대를 죽는 조건으로 문서화.
