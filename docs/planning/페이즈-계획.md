# 페이즈 계획 v3 — 조각투자 가치검증 (2026-08-08 주제 전환 반영)

> 이전 버전(약관 주제 v2)은 `docs/archive/2026-08-08-약관위험조건검증/planning/페이즈-계획.md`.
> 마감 역산: **9/5 제출 목표**(공식 마감 9/7 10:00의 이틀 버퍼) · 9/7~9/11 심사 접속 기간 무중단.
> **오늘 기준 D-30.** 주제를 한 번 갈아탔으므로 이전 계획 대비 착수가 8일 늦다 — 스파이크를 압축하고 게이트를 앞당긴다.

## 전환으로 달라진 것

1. **크리티컬 패스가 바뀌었다.** 이전엔 AI Hub 580 승인(외부 대기)이었다. 지금은 **죽는 조건 3건의 판별**이고, 이건 우리가 사흘이면 끝낼 수 있다 — 외부 대기가 사라진 게 이번 전환의 최대 이득이다
2. **데이터가 전부 무료·자동승인**이다. 국토부 실거래가·OpenDART 모두 신청 대기 없이 당일 호출 가능. ⚠️ 단 **OpenDART 구조화 API(DS006)에 투자계약증권·수익증권이 없어** 공시검색 C005·C010 목록 → 원문 XML 파싱 경로를 써야 한다 (8/8 확인)
3. **크롤링 법적 리스크가 사라졌다.** 플랫폼 크롤링 대신 OpenDART 공시를 쓰기로 해 이전 주제의 stream8 수칙(robots·TDM 회색지대)이 아예 불필요해졌다
4. **살아남은 자산**: 신뢰 스파인 전체, 디자인 토큰, 대회 양식 분석, 일반 리서치(stream1~4), 산타 리뷰·레드팀 프로세스
5. **버려진 자산**: 약관 분석 코어, AI Hub 의존 설계, 별표15 diff 엔진, 약관규제법 유형 매칭

**게이트 판정: ✅ 축 A 착수.** 축 B 단독 축소 시나리오는 발동하지 않는다. 2축(축산 라이브 + 부동산 사후) 구성을 그대로 간다.

> ⚠️ **위 판정은 전부 문서 기준이다.** 서비스키 실발급 + 뱅카우 9호 37두 이력번호 호출 테스트가 진짜 게이트이며 **Phase 1 첫 작업**이다.

## Phase 1 — 데이터 파이프라인 (8/11~8/18)

| 작업 | 내용 | 완료 기준 |
|---|---|---|
| **DART 수집기** | 공시검색 `pblntf_detail_ty=C005·C010` 목록 → 원문 `document.xml` 취득. 2026-07-28 기점 C010→C005 이동 처리 | 2026년 투자계약증권 8건 + 2023~25년 26건 원문 확보 |
| 신고서 파서 | 본문 텍스트화(항목 구조 보존). 보고서명 문자열 2차 필터 | 항목 단위 분할 성공률 측정 |
| **claim 추출 스키마 확정** | 검증 가능한 주장 단위 — 개체 이력번호 / 주소 / 공모가 / 수량 / 자금용도 / 사업기간 + 문서 좌표 | 스키마 v1 + 뱅카우 9호·카사 2건 수동 검증 |
| **축산물이력제 어댑터** | 이력번호 → 개체 실재·이력 조회 | 뱅카우 9호 37두 조회 성공률 |
| **국토부 실거래가 어댑터** | 법정동코드+계약년월 순회, 결과 정규화 (code.go.kr 테이블 내장) | 카사 10건 주소 100% 변환 + 비교군 n건 계수 |
| **비교군 충분성 실측** | Phase 0 이월분. 건물별 인근 유사 거래 건수 계수 | **n이 구조적으로 부족하면 ② 가격 층위를 축소하고 ①③으로 무게 이동** |
| 골드셋 착수 | 공모 문서 10~20건 수동 라벨(추출 정답) | 라벨 가이드라인 + 5건 선라벨 |

**게이트**: 뱅카우 9호 1건이 {claim 추출 → 이력제 대조 → 판정}까지, 카사 1건이 {주소 → 실거래 비교군 → 백분위}까지 통과하면 Phase 2 착수.

## Phase 2 — 분석 코어 (8/19~8/26)

| 작업 | 내용 | 완료 기준 |
|---|---|---|
| LLM claim 추출 | 비정형 신고서 → 검증 가능한 주장 목록. 신뢰 스파인 경유(출처 강제) | 골드셋 EM/F1 측정 시작 |
| **대조 판정 엔진** | claim 종류별 어댑터 라우팅 → **일치 / 불일치 / 확인 불가** 3값 판정. 근거 0건이면 판정 없음(약관 주제의 등급 불변식 이식) | 판정 규칙 명문화 + 테스트 |
| 백분위 산출 | 평당가·두당가 정규화 → 비교군 내 위치. **비교군 n이 적으면 백분위를 내지 않고 그 사실을 표시** | 카사 10건 백분위 + 비교군 수 노출 |
| 이행 이력 집계 | DART 전수에서 청약 미달·자기인수·정정신고 이력 추출 + 핀돈 폐사·사육 공시 이행 여부 | 발행사 단위 이력 카드 |
| 위험 조건 추출 | 신고서에서 불리 조건 표시(단정 금지, 원문 좌표 연결) | 조건별 문서 좌표 연결 |
| 근거 리포트 생성 | 3층위 결과를 출처 병기 서술로 | 출력 필터 통과분만 표시 |
| **스파인 도메인 교체** | 코퍼스 레지스트리·레드팀 시나리오·고지 문구를 조각투자 기준으로. 단정 금지 표현 재설계("저평가다"·"무조건 오른다" 계열) | 약관 잔재 제거, 레드팀 재통과 |

**게이트**: 뱅카우 9호가 입력→3층위→리포트까지 완주하고, 카사 1건이 ② 가격 층위까지 완주.
