### 방향 확정 (2026-08-13 사용자 결정)

1. **차별화 축 = "사용자 병목 줄이기".** 축산 STO 상품 프레임은 폐기하고 **조각투자 공시 검증 인프라**로 포지셔닝한다. 뱅카우는 상품이 아니라 **첫 실증 어댑터**다. 기존 서사("병목이 공백을 만든다")와 그대로 맞물리므로 **코드 방향 전환 비용은 0** — 화면 문구와 기획서 서사만 갈아끼운다.
2. **축 B 보호 승격.** 카사 1건 완주(주소 → 실거래 비교군 → 백분위)는 **어떤 경우에도 자르지 않는 보호 구간**이다. 비축산 어댑터가 곧 확장성의 기술 증명이기 때문이다. 축소 스위치를 아래 순서로 재배열한다.

   | 순서 | 축소 대상 |
   |---|---|
   | ① | 트랙레코드 상세 → 요약 카드로 축소 |
   | ② | 골드셋 20건 → 10건 |
   | ③ | 눈높이 프리셋 1종 |
   | ④ | 축 B **확장**(10건) → 1건 완주로 축소 |
   | ⑤ | 리플레이 UI 간소화 |
   | ⑥ | cron 자동 감시 → 수동 트리거 전환 + Blob 이벤트 적재 연기(S2 절감) |

   **사수 구간 = 축 A E2E + 라이브 재검증 + 축 B 1건.** 이 셋은 스위치 대상이 아니다.
3. **UI 원칙 "자기보고형 금지".** 화면 문장의 주어는 **공모·자산**이지 서비스가 아니다. "우리는 ~를 검증합니다" 계열 자기소개, 설득 서사, 실적 수치는 화면에서 빼고 **기획서와 `/methodology`가 담당**한다.
4. **홈 IA 확정.**
   - `/` = **청약 일정순(D-day) 공모 목록**이 본체. 한 줄 정의만 상단에 둔다.
   - `/offers/[id]` = 판정 옆 **인라인 신뢰 링크**.
   - `/methodology` = 설득 논증 통합.
   - 상세는 [`홈-IA-개편-2026-08-13.md`](홈-IA-개편-2026-08-13.md) 참조(동시 작성 중).

**S3.5 후속 — 판정 유효성 회복 (2026-08-15~16 · S3 잔여와 병행)**

> 배경(8/15 실측): 가축 7호·8호 리포트에서 **전 개체(40/40·66/66)가 성별 항목만 불일치** — 신고서 "수" vs 원장 "거세". 한우 수컷의 거세는 비육 표준 관행이므로 이는 리스크 신호가 아닌 **예상된 상태 전이**다. 여기에 mismatch의 화면 라벨이 "원장 미확인"이어서, 노이즈 106건이 정탐 1건(가축 9호 보관장소)을 매몰시켜 리포트 실효성이 무너졌다. 성별은 개체 동일성 확인의 보조 필드이자 경락가 지수 선택 입력으로 유지하되, 전면 노출 판정에서 내린다.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | **성별 판정 재분류** — `assessSex`에서 수→거세는 match + 전이 각주, 불가능 전이(암↔수 등)만 불일치 유지 | judge-engine 테스트 통과 |
| 2 | **라벨 의미 정정** — mismatch "원장 미확인" → "원장 불일치", "미확인" 어휘는 unverifiable 전용으로 | "원장 미확인" 문자열 전수 스윕 0건 |
| 3 | **리포트·스냅샷·눈높이 서술 재생성** — fake 선검증 후 live 재대조 | 7호·8호 불일치 106→0, 9호 보관장소 1건 잔존 |
| 4 | **리포트 위계 역전** — 정정 계보·트랙레코드를 상단으로, 개체 필드 매트릭스는 "전수 요약 한 줄 + 접힌 부록"으로 강등. 진짜 불일치만 펼침 | 첫 화면 = 정정·트랙레코드·요약, 자기보고형 금지 유지 |

**게이트**: 리포트 첫 화면이 "투자자가 알아야 할 것" 순서(정정 계보 → 트랙레코드 → 원장 대조 요약)로 읽히고, 성별 노이즈가 판정 집계에서 사라진다.

## 전환으로 달라진 것

1. **크리티컬 패스가 바뀌었다.** 이전엔 AI Hub 580 승인(외부 대기)이었다. 지금은 **죽는 조건 3건의 판별**이고, 이건 우리가 사흘이면 끝낼 수 있다 — 외부 대기가 사라진 게 이번 전환의 최대 이득이다
2. **데이터가 전부 무료·자동승인**이다. 국토부 실거래가·OpenDART 모두 신청 대기 없이 당일 호출 가능. ⚠️ 단 **OpenDART 구조화 API(DS006)에 투자계약증권·수익증권이 없어** 공시검색 C005·C010 목록 → 원문 XML 파싱 경로를 써야 한다 (8/8 확인)
3. **크롤링 법적 리스크가 사라졌다.** 플랫폼 크롤링 대신 OpenDART 공시를 쓰기로 해 이전 주제의 stream8 수칙(robots·TDM 회색지대)이 아예 불필요해졌다
4. **살아남은 자산**: 신뢰 스파인 전체, 디자인 토큰, 대회 양식 분석, 일반 리서치(stream1~4), 산타 리뷰·레드팀 프로세스
5. **버려진 자산**: 약관 분석 코어, AI Hub 의존 설계, 별표15 diff 엔진, 약관규제법 유형 매칭
