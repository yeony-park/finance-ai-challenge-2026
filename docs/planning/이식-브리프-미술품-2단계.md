## 미션

라이선스 Yellow(플랫폼 3사 서면 확인)와 **무관하게** 복원 가능한 아트체크의 상세함을 /art 착지에 복원한다. 데이터 원천은 1단계와 동일 — **정규화본 5상품(content/art.ts)과 DART 유래 사실뿐**. 새 데이터 도입 금지.

## 범위 (P1→P4 순서 고정)

- **P1 확장 카드**: 5상품 카드에 접이식(`<details>`) 상세 추가 — 문서 좌표(공모 공고·표·행), 검산 세부(취득가+발행비용=공모가 산식 전개), 한계 주석 전문, 근거 상태 3값의 쉬운 캡션(`verdict-captions.ts` 재사용). 원본 products/[id] 7탭 중 요약·공모가·근거 탭의 게이트 무관 요소만.
- **P2 차트 착지 렌더**: 1단계에서 이식만 되고 미렌더인 차트 6종 중 **정규화본 수치로 산출 가능한 것만** 착지에 렌더 — ① 상품별 공모금액 구성(취득가·발행비용) 스택바 ② 5상품 공모금액 비교 컬럼. 경매·트랙레코드·회수 데이터가 필요한 차트는 렌더 금지(억지 산출 금지 — 1단계 원칙 유지). 색은 `--ds-chart-*`·잉크 계열만.
- **P3 인페이지 비교**: 5상품 중 2~3개 선택 → **사실 행만** 비교표(공모금액·취득가·발행비용·검산 결과·기준일·상태·DART 문서 좌표·근거 상태). 선택 상태는 URL(`?compare=`)로 공유 가능하게(클라이언트 컴포넌트, 서버 왕복 없음). 원본 compare의 "AI 최종 판단"·결론 배너류 부활 금지. localStorage 트레이는 단일 페이지 5상품이라 불요 — 도입하지 말 것.
- **P4 계산 기준 블록**: 방법론 산식 중 게이트 무관 부분(구성 검산·차이율 산식)만 접이식 설명 블록으로. "네 단계 최종 판단" 관련 서술 금지 유지. 산식 서술의 주어는 화면·수치이지 서비스가 아니다(자기보고형 금지).
