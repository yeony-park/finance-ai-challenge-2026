## Phase 3 — 일화 프로빙 (③ 어렴풋이 아는 것)

P1 (진입장벽 포커스 느낌의 출처): 그 느낌을 받은 구체적 장면은?
A-P1: "수상작들이나 예시 주제들이 그런 것들을 말해주고 있었어. 도입장벽 완화 같은 것들?"
→ 출처 특정됨: 공모전 페이지의 예시 주제·과거 수상작에 '도입장벽 완화' 류 주제 존재. 여전히 문구 수준은 흐릿 → ④에서 deep research로 검증(공모전 페이지 재확인) 예정
→ 추출 규칙(잠정): "심사 어필 축 = 금융 접근성·진입장벽 완화에 서비스를 명시적으로 정렬시킬 것"

P2 (입문자 전환 조건 — 본인의 판단 기준): 100만 원 가정, 뭘 확인하면 넣고 뭘 보면 접나?
A-P2: "수익 구조도 명확해야 할거고, 구매하는 곳이 믿을만한지 봐야하지 않을까"
→ 전환 2대 기준 추출: ① 수익 구조 명확성(수익 발생 메커니즘·수수료·정산) ② 판매 주체 신뢰성(발행사/플랫폼)
→ 기존 자산 매핑: ①=정산 실측(데이터젠 1호 13.1%)·가격 산식·가격 층위 / ②=발행사 트랙레코드 카드·정정 계보 — 엔진이 정확히 이 두 질문에 답함

P2-후속 ('믿을만함'의 판단 신호): 화면에 뭐가 보이면 믿게 되나?
A-P2-후속: "그건 사실 모르겠어.. 잘 모르는 분야니까. 여기서 AI가 도와주는 것도 좋지 않을까?" [unresolved]
→ ★★ 핵심 통찰: 입문자는 정보만 없는 게 아니라 **판단 기준 자체가 없다**. 제품의 역할 = "믿을만한지 보려면 무엇을 확인해야 하는지"를 AI가 안내하고, 각 항목에 엔진의 실측(확인됨/대조 불가)을 붙여주는 것. "이 상품 믿어도 돼?"(권유 위험)가 아니라 "믿을만한지 보는 법 + 이 상품의 확인 현황"으로 답하는 구도 — 기존 reviewQuestions·확인 질문 생성 설계와 정합
