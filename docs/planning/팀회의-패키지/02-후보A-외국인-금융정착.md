# 후보 A — 국내 체류 외국인 금융 정착 AI Agent

> council 4/4 지참 확정. 리서치 균형 최상 후보. 단 "진정성 검증"에 대비해야 함.

## 문제 (한 줄)
체류 외국인 ~280만 명, 계좌 보유율 ~70% — 외국인등록증 발급 전 계좌 개설 거절이 빈발하고 은행별 요건이 제각각인데, **은행 앱들(SOL Global, Hana EZ)은 자사 상품 안내에 갇혀 있어 "비자 유형별로 지금 뭐가 가능한가"를 중립적으로 알려주는 창구가 없다.**

## 타깃·채널 (기획서 3번 대응)
- 세그먼트를 하나로 좁히기 권장: **유학생(D-2/D-4)** 또는 **근로자(E-9)** — 회의에서 선택
- 채널: 모바일 웹, 다국어(영어+중국어 또는 베트남어 등 2~3개로 한정해 품질 확보)

## 서비스 컨셉
비자 유형·체류 단계 입력 → **"지금 가능한 금융 행동" 내비게이션**: 은행별 계좌 개설 요건·필요 서류 비교, 모바일 외국인등록증 활용법, 신용 형성 로드맵(첫 카드·소액 대출 경로), 송금 옵션 수수료 비교, 외국인 대상 피싱 수법 경고 — 전부 모국어로, 출처 링크와 함께.

## 생성형 AI 역할 (기획서 5번 대응)
제도·요건 문서 RAG 질의응답(출처 강제) / 비자·상황별 개인화 로드맵 생성 / 다국어 응답 / 서류 체크리스트 생성.

## 검증된 데이터 (data-first)
- **금융상품한눈에 API** (finlife.fss.or.kr) — 예적금·대출 상품 비교, 키 즉시 발급, 무료
- 하이코리아(hikorea.go.kr) 비자·체류 제도 공개 문서
- 은행별 외국인 계좌 개설 안내 페이지 (공개)
- 모바일 외국인등록증 제도 안내 (2025-03 시행, 6개 은행)
- 서민금융진흥원 API (data.go.kr) — 보조
- 금감원 보이스피싱 사례 (피싱 경고 모듈용)

## 하네스 스케치
서브에이전트: 제도 RAG / 상품 비교(API) / 로드맵 생성 / 번역·현지화 + 신뢰 스파인(04). 비자·법률 정보는 **항상 원문 출처 병기 + "최종 확인은 기관에" 고지** (오정보 = 체류 문제 직결).

## 승산
공백 실재(중립 통합 내비게이터 부재 — "혁신금융 트렌드에 언급만 되는 단계") / 다국어 데모의 즉각적 임팩트 / 포용금융 수상 코드 / 은행 공동개최사들의 실제 관심사(외국인 고객 유치 경쟁 중) / 데이터 전부 공개.

## 결정적 리스크 (council)
1. **진정성 공백 — PT에서 "외국인 사용자를 몇 명 만나봤나" 한 질문에 무너질 수 있음** (Critic). 팀에 외국인 접점 0.
2. **비자·법률 오정보 할루시네이션** — 틀리면 체류에 실해. 출처 강제 + 범위 한정으로 방어.
3. 예시 주제라 경쟁 존재. 다국어 품질 검증 부담(언어 수 한정으로 통제).

## 죽는 조건
- **8/14까지 외국인 사용자 인터뷰 2~3명을 확보하지 못하면** (유학생 커뮤니티·교내 유학생회·지인 경유 — 확보 시 기획서 "사용자 조사" 항목이 오히려 무기가 됨)

## 현직자에게 물을 것
창구 외국인 고객 빈도·유형 / 계좌 개설 거절의 실제 사유(내부 지침) / 외국인 고객이 반복적으로 묻는 것
