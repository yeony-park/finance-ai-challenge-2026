> **주제 확정 시한: 8/7.** 5주 대회에서 선정에 1주 이상 쓰는 건 사치다. 제출 마감 9/7 10:00.

## 0. 사전 공유 (회의 전 읽기)
- 후보 원페이저 4장 (01·02·03·05) + 신뢰 스파인 (04)
- 05 후보 F(조각투자 가치검증)는 8/2 신규 접수 — council 미검증이므로 회의에서 동일 잣대로 검증
- 배경 필요 시: `docs/research/00-종합-리서치-보고서.md`

## 1. 은행 현직자 인터뷰 (15분, 가장 먼저)

주제별 판단 전에 듣는다 — 어느 답이 나오든 후보 하나가 강해진다.

- 구체적으로 무슨 업무를 하나? (창구/여신/IT/리스크…)
- **요즘 업무에서 제일 짜증나거나 비효율적인 것 3가지는?** (2025 대상팀 공식: 현장 페인포인트가 최고의 주제)
- 창구/업무에서 외국인 고객을 얼마나 접하나? 계좌 개설 거절의 실제 사유는? → [후보 A 검증]
- 보이스피싱 지급정지 요청을 처리해본 적 있나? 피해자들이 실제로 뭘 몰라서 헤매던가? 내부 대응 매뉴얼이 있나? → [후보 B 검증]
- 방카슈랑스(보험 판매) 경험이나 보험 쪽 지인이 있나? → [후보 D 생사 결정]
- 담보평가·감정가 실무 경험이 있나? 조각투자·STO 관련 고객 문의를 접해봤나? → [후보 F 검증]
- 은행 내부에서 생성형 AI 통제(보안 규정)는 어떻게 다루나? → [신뢰 스파인 리얼리티]

## 2. 팀 역량·가용시간 확인 (10분)
- 팀원3(미상): 스택, 강점, 가능 역할 (프론트/디자인/QA 커버 여부가 관건)
- 전원: 주당 투입 시간, 9월 첫 주 가용성(제출 직전), LLM API 비용 분담 (심사 5일 무중단 서빙 포함 예산)

## 3. 후보 검토 (원페이저당 5분 + 토론)
- 순서: B → A → F(신규) → D(조건부)
- F는 council 미검증 신규 후보 — 죽는 조건(시연 가능 공모 3건 특정, 비교군 실효성, 혁신금융 목록 중복 확인)을 회의에서 판정
- 각 후보의 "죽는 조건"이 이미 발동했는지부터 확인
- **재조합 옵션을 명시적으로 논의**: B×시니어 / B×외국인 — "타깃 한 줄" 변경이 예시 주제 군중과 갈라서는 최저비용 차별화 (Skeptic)

## 4. 결정 (15분)
- 옵션 1: 즉시 확정 (현직자 정보가 결정적일 때)
- 옵션 2: **상위 2개로 압축 → 48시간 데모 스파이크 → 8/7 확정** (권장)
- 주의(Critic): 셋 다 "틀리면 사람이 다치는 정보 제공형" — 출처 강제·확인 단계 체계를 여러 번 만들 수 없다. 스파이크는 최대 2개.

## 5. 역할 분담 초안 + 즉시 착수 항목
- **신뢰 스파인은 주제와 무관하게 지금 착수 가능** (04 문서): 출처 강제 RAG 뼈대, 가드레일, 배포 파이프라인
