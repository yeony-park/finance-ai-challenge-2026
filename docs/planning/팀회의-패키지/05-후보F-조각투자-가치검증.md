## 문제 (한 줄)
조각투자 자산의 실물 존재는 신탁 구조로 담보되지만, **공모가가 적정한지·사업자가 과거 약속(배당·청산)을 지켰는지를 소비자가 독립적으로 확인할 수단이 없다.** 가격 정보는 사실상 공모 페이지 한 곳뿐.

## 시장 타이밍 (2026-08-02 검증 — 기획서 원문에서 업데이트됨)
- 전자증권법·자본시장법 개정 **2026-01-15 국회 통과, STO 제도 시행 2027-02**. 유통플랫폼 예비인가 사업자 선정 완료(2026-02).
- 1세대 부동산 플랫폼 **카사·펀블 폐업 수순**(카사: 2026-03~04 자산 처분, 잔여 상암235빌딩 매각 투표 중 — sedaily.com/article/20058199). 반면 투자계약증권은 활발: 뱅카우 15개 발행·5개 청산·2026년 100억 공모 계획, 열매컴퍼니 2026 상장 도전.
- **포지셔닝**: "시장 축소 대응"이 아니라 **"2027-02 제도 시행으로 신규 발행이 쏟아지기 직전, 투자자 보호 인프라 공백을 선점"** + 1차 폐업 사태(회수 지연)가 필요성의 실증 사례.

## 타깃·채널 (기획서 3번 대응)
조각투자 검토 중인 개인 투자자(2030 중심), 모바일 웹. 공모 페이지 URL/증권신고서를 넣으면 검증 리포트를 받는 단발성 도구라 회원가입 없는 데모에 적합.

## 서비스 컨셉 — 3층위 교차 검증
| 층위 | 검증 대상 | 방법 |
|---|---|---|
| ① 가격 | 공모가가 시장가 대비 적정한가 | 국토부 실거래가와 대조, 평당가 백분위 산출 |
| ② 이행 | 사업자가 약속을 지켜왔는가 | 과거 상품 배당 지급률·청산 지연 이력 집계 |
| ③ 설명 | 공모 문서에 불리한 조건이 숨어 있나 | LLM으로 비정형 문서에서 위험 조항 추출 |

파이프라인: 입력(URL/PDF) → LLM 구조화 추출{주소·연면적·공모가·배당계획·청산조건} → 법정동 코드 정규화 → 실거래가 API 수집 → 백분위 산출 → 이행 이력 대조 → 근거 서술 리포트.

## 생성형 AI 역할 (기획서 5번 대응)
AI의 존재 이유는 ③: 공모 설명서는 자유 서식 비정형 문서로 규칙 기반 파싱 불가 → **LLM 구조화 추출이 ①②의 정량 비교를 성립시키는 전제**. + 점수 근거의 자연어 리포트 생성(출처 병기). "AI가 장식" 비판(후보 B의 약점)에서 구조적으로 자유로움.

## 검증된 데이터 (data-first) — 전부 공개·무료, 2026-08-02 실재 확인
- **국토부 실거래가 오픈API** (data.go.kr/data/15126463 외): 상업업무용·아파트·오피스텔 매매. 무료·자동승인, 법정동코드 5자리+계약년월 요청, 개발계정 일 10,000건 확인
- **OpenDART 증권신고서 API** (opendart.fss.or.kr, DS006/2020055): 조각투자 공모는 증권신고서 제출 의무 → 공모가·자산내역·배당계획·위험요소가 **공신력 있는 공시로 존재. 기획서 원안의 플랫폼 크롤링(robots.txt 리스크)을 대체하는 업그레이드**
- 행정표준코드 법정동코드 (code.go.kr) — 주소→지역코드 변환
- 이행 이력: 플랫폼 공지 기반 사전 구축 데이터셋(MVP 범위)
- 미술(서브): 경매 낙찰가 DB 오픈API 부재, 집계치만 공개 — 시연 가능 시에만. 음악: 자기순환 검증 구조(플랫폼 자체 공시뿐)라 제외

## 하네스 스케치
서브에이전트: 문서 구조화 추출 / 실거래 비교(API) / 이행 이력 대조 / 리포트 생성 + 신뢰 스파인 전체 적용. 출처 강제 RAG가 "이 점수의 근거는 이 실거래·이 공시"로 직결 — 스파인과의 결합도는 후보 중 최상.

## 승산
경쟁 서비스 미발견(수익률 나열식 비교 블로그 수준뿐, 단 완전한 시장조사 아님 — 혁신금융서비스 지정 목록 재확인 필요) / 정량 데이터 기반이라 데모 임팩트 즉각적 / 소비자 보호 어젠다 정면 / 예시 주제 군중(피싱·외국인·포용금융)과 완전히 다른 레인.

## 결정적 리스크
1. **데모 소재 고갈** — 부동산 공모가 살아있는 플랫폼이 9월에 희소할 수 있음(카사·펀블 폐업). 데모는 과거 공모 아카이브 재검증 형태가 될 가능성 — "사후 검증 리포트"로 프레임 전환 필요
2. **자산군 확장의 비용** — 주력 검증 로직(실거래가 대조)은 부동산 전용. 한우·미술은 시장가 대조 데이터가 약해 자산군별 재설계 필요 → MVP는 부동산 한정 엄수
3. **도메인 검증자 부재** — 증권·부동산 감정 실무자가 팀에 없음. D를 죽인 것과 같은 결의 약점. 은행 현직자의 여신·담보평가 경험이 소생 변수
4. **점수의 책임** — "적정하지 않다" 판정이 틀리면 사업자 명예훼손·투자 손실 유도 양방향 리스크. 백분위 "위치 제시"로 한정하고 판정 단정 금지(신뢰 스파인 출력 필터로 강제)
