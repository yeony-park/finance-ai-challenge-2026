# 후보 D — 보험 특화 서비스 (조건부 지참)

> council 표결 분열(지참 2 / 조건부 1 / 컷 1). **생존 조건: 보험 지식 검증자 확보.** 조건 미충족 시 회의에서 즉시 폐기.

## 왜 후보에 남겼나
- **생명보험협회가 2026년 신규 공동개최사** — 심사장에 보험 어젠다가 앉아 있음
- 보험업 AI 활용은 가능 업무 83개 중 8개(여백 최대), 참가작 풀에서 보험 주제 희소 예상
- 리서치가 "블루오션"으로 지목한 유일한 영역

## 각도 선택 (중요 — 프리미스 체크)
- ⚠ **"실손 청구 내비게이션"은 폐기 확정 (2026-07-31 검증)**: 실손보험 청구 전산화(실손24)가 2024-10-25 병원급 → **2025-10-25 의원·약국까지 확대 시행**, 참여 요양기관 10,920개(연계율은 ~10%에서 상승 중). 공백이 제도적으로 닫히는 중 — 이 각으로 가면 "이미 정부가 하고 있는 것" 지적에 즉사. (출처: fsc.go.kr/no010101/85456)
- 대안 각 1: **보장 사각지대 진단** — 내 보험증권들을 넣으면 "뭐가 겹치고 뭐가 비었나"를 약관 기반으로 해설
- 대안 각 2: **분쟁 사례 기반 가입·청구 길잡이** — 금감원 분쟁조정 사례를 학습한 "이런 경우 보험금이 안 나옵니다" 사전 경고

## 검증된 데이터 (data-first)
- FINE 표준약관 전문 (fine.fss.or.kr) — RAG 코퍼스
- 생보협회·손보협회 상품비교 공시 (pub.insure.or.kr 등)
- 금감원 분쟁조정 사례집·보도자료 (공개)
- 보험연구원 리포트 (통계·맥락)

## 승산 vs 리스크
- 승산: 경쟁 밀도 최저 + 협회 어젠다 + 약관 RAG는 팀 기술로 조립 가능
- 리스크 (council):
  1. **도메인 검증자 부재** — 은행 현직자는 보험 판정자가 아님(범주 오류, Skeptic). 약관 해석 오답 하나(소액암 분류류 엣지케이스)로 심사장에서 즉사 가능 (Critic)
  2. 보험 지식 습득 비용이 5주를 잠식 (Pragmatist의 컷 사유)
  3. 증권(보험증권) 실물 데이터 없음 → 샘플 증권 시나리오로 데모 구성 필요

## 죽는 조건 (명시적)
- **회의에서 보험 지식 검증자(현직 설계사·손해사정사·보험사 재직 지인, 또는 현직자의 방카슈랑스 경험)를 특정하지 못하면 폐기**
- 실손24 확인 결과 대안 각까지 제도로 커버되고 있으면 폐기

## 현직자에게 물을 것
방카슈랑스 판매 경험 유무 / 보험 업권 지인 / 은행 창구에서 접하는 보험 관련 고객 불만
