# JeomJeom — 조각투자 입문자를 위한 AI 안내 + 독립 검증 플랫폼

> 2026 금융 AI Challenge 출품작. 팀 4개 작업 계보(검증 엔진 / 미술품 / 돼지·미술품 리서치 / 공통 골격)의 통합·재구성 요구사항 문서.
> v0.2 (2026-08-15) — 4관점 리뷰(사실 검증·규제 경계·시니어 PM·일관성, 발견 58건) 반영판. 근거: 브랜치 전수 분석, IDI 지식 활성화 인터뷰, 출처 검증 리서치.

## Problem

조각투자(투자계약증권·수익증권) 입문자는 정보가 아니라 **판단 기준이 없다**. 뭘 확인해야 상품과 판매 주체를 믿을 수 있는지 모르고(타깃 본인 증언: "그건 사실 모르겠어.. 잘 모르는 분야니까"), 주식과 다른 라이프사이클(청약 진입, 즉시 매각 불가)에 당황하며, 실물 자산의 소멸·손상이라는 1차 공포를 갖고 있고, 질병 등 사건 공시는 상품 화면이 아닌 게시판에 흩어져 있어 직접 대조해야 한다. 이 상태를 방치하면 입문자는 시작하지 못하거나, 확인 없이 시작한다 — 두 결과 모두 2027-02 유통 개방으로 커질 시장의 신뢰 기반을 해친다.

기존 플랫폼(발행·판매 주체)은 구조적으로 자기 검증을 할 수 없고, 국내에 제3자 검증 레이어는 **확인되지 않는다** (팀 리서치: 혁신금융서비스 지정 1,112건을 금융위 보도자료·8종 검색어 교차로 확인한 결과 제3자 검증 지정 0건 — 단, 전수 열람은 미완).

## Evidence

- IDI 인터뷰 (2026-08-15, 타깃 페르소나 본인): "비트코인이나 저축 등 다른 투자 상품에 비해 어떤 장점이 있는지 잘 모르겠어" / "실물이 존재하는 상품에 대한 투자잖아? 오히려 그래서 좀 걱정돼. 생물이 죽을 수도 있고" / "청약이라는 절차 자체가 낯설다 … 매각할 때도 바로 되는 게 아니라서" / (믿을만함의 판단 신호를 묻자) "그건 사실 모르겠어 … 여기서 AI가 도와주는 것도 좋지 않을까?"
- 관찰 (IDI): 뱅카우에서 질병 등 사건이 해당 호 화면이 아닌 게시판에 게재되어 "비교 대조 귀찮음" → 사건·정정의 상품 화면 귀속 표시 요구(Scope)의 직접 근거.
- 시장 구조 (리서치 2026-08-15, 출처 부착): 2024년 샌드박스 4사 연간 거래(매수액) 약 145억 원(전자신문 2026-08-09) vs 2030년 토큰증권 **시가총액** 전망 367조 원(국회입법조사처 인용, EBN 2025-11-01) — 실거래 시장은 미개발, 개방은 임박. 자본시장법·전자증권법 개정 2026-01-15 국회 통과 → 2026-02-03 공포, (전자증권법 기준) 2027-02-04 시행으로 증권사 유통·장외거래중개업 허용(금융위 보도 86064; 기획서 인용 전 시행일-법률 매핑 재확인).
- 진입장벽 완화의 유효성 방증: 루센트블록 자체 설문(2025-10~11 실시, 2025-12 보도) "실물 자산 진입장벽 낮아졌다" 89.9% — 발행사 자체 조사임을 명시해 근거로만 인용(사용자 대면 콘텐츠 사용 금지, 표현 규칙 참조).
- 신뢰 문제의 실재: 펀블 투자중개업 인가 미취득 → 서비스 종료·청산 절차(2026-04-29 보도). 발행사 트랙레코드 실측: 8-2회차 일반 청약률 73% 미달 + 운영사 잔여 2.087억 원 인수(DART 원문, 팀 실측).
- 활용 데이터 (실보유·실가동): ① DART 공시 원문 — 증권신고서 47건 확보 + 2026년 투자계약증권 공모 전수(8건) 분류 실측 ② 축산물이력제 ③ 축평원 경락가(2023-11~2026-08 수집) ④ 국토부 실거래가(RTMS, 키 상태 확인 필요). 미술품 공공 축(K-ARTMARKET 등)은 후보 단계.
- 공모전 정합 (daker.ai 공식 API 원문, 2026-08-15 확보): 공식 주제 "AI 기반의 금융 현안 해결 아이디어 및 웹서비스 개발", 공식 과제 설명 "금융소비자 특성과 서비스 채널을 고려한 맞춤형 금융 AI 서비스를 기획하고 실제 작동하는 웹서비스로 구현", 예시 주제 5번 "…AI 기반 포용적 금융서비스", 2025 수상작 패턴 = 특정 소비자 세그먼트 맞춤형(소상공인·임산부).
- Assumption — 입문자 유입 규모: 최신 전수 투자자 통계 부재(검증치는 연도별 단편: 소유 회원 40만 '24말~약 50만 '25-12 등). "많아질 것"은 법제화·전망치 기반 가정 — needs validation via 시장 지표 추적. 인용 시 연도 명시.

## Users

- **Primary**: 조각투자 입문자 — 금융 지식이 얕고, 플랫폼 앱(뱅카우·핀돈·소유 등)을 열어봤지만 청약 경험은 없는 일반 소비자. 트리거: 법제화 보도·플랫폼 광고·주변 언급으로 관심이 생겼으나 "뭘 봐야 할지" 몰라 멈춰 있음. 채널: 웹(데스크톱·모바일 반응형 필수 — 심사위원·입문자 모두 모바일 접속 개연성 높음).
- **Secondary (수용 맥락)**: 공모전 심사위원 — 기획서 필수 7항목 관점으로 산출물을 평가.
- **Not for**: 매수·매도 추천을 원하는 사용자(제공하지 않음), 전문 투자자용 고급 분석·트레이딩 도구.

## Hypothesis

We believe **"확인해야 할 항목을 AI가 스캐폴딩하고, 각 항목에 공시-공공원장 대조 실측(일치/원장 불일치/대조 불가)을 붙여주는 입문자 안내"**가 **판단 기준이 없어 시작하지 못하는 문제**를 **조각투자 입문자**에게 해소해 줄 것이라 믿는다.
We'll know we're right when 비전문가 테스트 참가자가 도움 없이 첫 세션에서 **(a)** 질문 또는 카테고리 선택 → 상품의 확인 현황(=상품별 검증 리포트)에 도달하고, **(b)** 세션 후 "이 상품에서 확인해야 할 항목"을 3가지 이상 스스로 열거하며(판단 기준 획득의 직접 프록시), **(c)** AI 응답의 모든 사실 문장이 출처·기준일을 갖는다.

## Scope

MVP 항목은 3계열로 라벨한다 — **[가설]** 가설 검증 코어 / **[제출]** 공모전 제출 요건 / **[계약]** 팀 병렬 작업 계약. 플래너는 [가설] 항목만 가설 테스트의 선행 조건으로 취급한다.

**MVP**

1. **[가설]** 입문자 메인 화면: AI 대화형 검색(빈 검색창 금지 — 예시 질문 상시 노출, 문안은 교육·확인 절차 수준으로 제한) + 조각투자 첫걸음 설명 밴드(쉬운 언어) + "어떻게 검증하나" 방법론 밴드(3층 검증 소개·실측 커버리지 — 정의는 공통 명세 v1로 위임. 신뢰·확신 표현의 주어는 서비스 방법론에 한정).
2. **[가설]** AI 안내의 4가지 응답 유형: ① 입문 교육(출처 부착) ② 카테고리·상품 라우팅(사용자가 명시적으로 지정한 대상에 한정 — AI 주도 상품 선별·우선 노출·비교 제시 금지. "어떤 상품이 나은가" 질문에는 판단 기준 교육으로 응답하고 상품을 지목하지 않음) ③ 검증 사실 인용(확인 현황 + 확인 항목 체크리스트 + 미확인 항목의 "확인 질문" 변환 — 체크리스트는 확인 절차 안내이며 투자판단이 아님을 화면 고지) ④ 범위 밖 질문(타 금융상품·세무·법률)의 표준 거절·공식 채널 안내. 근거가 없으면 "대조 불가"로 답하고, 모든 표면(친화적 문체 포함)에 표현 경계 필터가 예외 없이 적용된다.
3. **[제출][가설]** 4카테고리 균등 분기·착지: 카테고리마다 최소 1개 이상의 실데이터 확인 현황 + 층별 지원 선언(검증 불가 층의 정직 표기) + **사건·정정의 해당 상품 화면 귀속 표시**(게시판 분리 문제의 해소 — IDI 근거) + 노출 상품 선정 기준(검증 가능 데이터 존재 여부) 화면 고지.
4. **[계약]** 공통 명세 v1 — 팀원 4명(부동산=문수, 한우=원준, 돼지=연정, 미술품=현석)이 병렬 착수 가능한 계약. 모든 카테고리는 **공통 검증 엔진 위에** 얹힌다(새 자산군 추가 시 공통 계층 변경 없이 확장 가능, 카테고리 간 화면 구성·판정 표기 일관). 필수 계약 요소:
   - 판정 어휘 2층: 사실 판정 3값(일치/원장 불일치/대조 불가) + 근거 상태 어휘(기존 화면 5상태와 엔진 검증가능성 6값의 정합 — 명세에서 확정)
   - 공통 evidence 최소 구조: 기존 9필드(claim/value·unit/source_url/as_of/fetched_at/subject_id/status/method/limitations) 계승·개정 — 구 status 4값은 판정 어휘 2층으로 대체됨을 명시
   - **개인정보·실명 마스킹 규칙 + 익명화 게이트(누출 0건) 전 카테고리 공통 적용.** 실명 표기 예외 기준: DART 법정 공시상 공개된 발행인명 등에 한정, 자연인 정보 불가 — 익명 슬러그 정책과 실명 데이터 자산의 충돌 해소 포함(Open Questions)
   - 표현 규칙: 권유·보장·예측·등급 금지 + 근거 없는 시세·인과관계 생성 금지 + 조각투자 시작·참여 촉구 문안 금지 + 발행사·플랫폼 자체 조사 수치의 사용자 대면 콘텐츠 사용 금지 + 상품·발행사를 주어로 한 신뢰·보증 표현 금지
   - 데이터 라이선스 게이트: 공개 화면에는 Green(이용제한 없음 명시) 또는 서면 확인 완료 자산만. 미확인 자산은 원문 링크·최소 사실 인용으로 격하. 자산별 출처·라이선스·수집 방법 메타데이터 필수
   - 대화 입력 개인정보 처리: 계정·식별자 비수집, 입력 로그 개인정보 자동 마스킹 후 저장, 보존 기간 명시, 외부 AI 모델 전송 사실을 포함한 처리방침 화면 고지
   - 고정 고지 문안 세트(전 표면): 투자권유·자문·중개 아님 / AI 답변 오류 가능성 / '검증'은 공시-공공원장 대조에 한정(진위·가치·수익 보증 아님) / 법률·세무 자문 아님 / 발행사·플랫폼과의 독립성. + 발행사 이의제기·정정 요청 채널
   - 데이터 신선도 표기: 모든 화면에 기준일·수집 시각 표기, 제출 동결 기간의 데이터 갱신 정책은 Open Questions에서 확정
5. **[제출]** 기존 검증 산출물의 계승: 상품별 검증 리포트·정정 계보·트랙레코드가 새 IA에서 접근 가능(기존 공개 URL의 딥링크 연속성 포함) + **신뢰 스파인 전 파이프라인 계승 — 입력 스크리닝 → 출처 강제(미등록 출처 자동 보류) → 출력 필터 → 요청 한도 — 와 레드팀 러너**. 검증 데이터·인용 사실은 사전 생성 캐시에서만 읽는다(심사 기간 화면 가용성이 외부 데이터 API 상태에 의존하지 않기 위함). AI 추론 호출은 별도 경계(요청 한도·비용 상한)로 관리하며, 인용 사실은 캐시 출처로 한정.

**Out of scope**
- 투자 등급·추천·비교 우열 판정 (4등급 어휘 포함) — 금소법 §22 광고·중개 경계, 팀 원칙("판정하지 않는다") 위반
- **체크리스트·판정의 상품 단위 집계 점수·통과율·배지·서열화 표시** — 집계는 사실상 등급. 항목별 사실 판정과 근거만 표시
- 청약·매매·중개 기능, 실계좌·마이데이터 연동 — 판매대리·중개업 등록 필요 영역
- 수익률·가격 예측, 원금 보장성 표현, 근거 없는 시세·인과관계 생성 — 표현 경계 필터의 차단 대상
- 공식 감정평가·진위 판정·등기·법률 검토의 대체 — 기존 팀 범위 문서에서 승계, 특히 미술품 경계 고지
- 크롤링 기반 데이터 수집 — 팀 데이터 수집 신호등 Red (저작권법 §93, 대법원 2023도17354)
- **허가 없는 제3자 플랫폼·CDN 호스팅 이미지의 화면 렌더링(핫링크·프레이밍 포함)** — 작품·상품 이미지는 원문 링크 텍스트로만, 화면 이미지는 자체 제작·허가 자산 한정
- 사용자 개인 검토 노트(기존 범위 문서의 제공 항목) — MVP 제외: 세션 개인정보 보존 부담 대비 가설 검증 기여 낮음. **팀 합의 필요로 표기**
- 카테고리별 특화 심화 기능 — 각 팀원 담당 영역 (이 PRD는 공통 계층만 규정)

- [ ] 'Copilot' 명칭과 돼지 페이지 대화 UI의 전역 AI 안내 통합 방향 (기존 규칙: Copilot은 돼지 전용)
