## ★ 차별화 후보 (남들이 모르는 구체 지식)

1. ★★ **입문자는 정보가 아니라 판단 기준 자체가 없다** — "믿을만한지 뭘로 판단하냐"는 질문에 타깃 본인이 "모르겠다, AI가 도와주면 좋겠다"고 답함. 제품의 역할 = 확인 항목을 스캐폴딩하고 항목별로 엔진 실측(확인/대조 불가)을 붙이는 것. 등급 판정 없이 신뢰 질문에 답하는 유일한 구도.
2. ★ **뱅카우 게시판 분리 관찰** — 질병 등 사건 공시가 해당 호(상품) 화면이 아니라 게시판에 따로 올라와 사용자가 직접 비교·대조해야 함. 상품 귀속 사건 타임라인(정정 계보·감시 이벤트)의 직접적 사용자 근거.
3. ★ **라이프사이클 이질성** — 청약이라는 진입 절차도, 즉시 매각 불가라는 출구 제약도 주식 멘탈모델과 충돌. 입문 교육의 뼈대 축.

## ① 아는 것

- 사용자 본인이 타깃 페르소나(초보자). 개념 자체가 "기괴하고 신기함" — 한우 몇십등분 소유가 낯섦, 비트코인 연상
- 타 상품(비트코인·저축) 대비 가치제안을 모름 → 비교 설명이 입문 콘텐츠에 필수
- **실물 리스크 직관의 역전**: 실물(생물·작품)은 죽거나 손상될 수 있어 "오히려" 불안, 블록체인은 안 사라져서 안심 → 실물 기반 상품의 1차 공포는 소멸·손상·실재 여부 = 검증 레이어가 답할 수 있는 정확한 지점
- 정보 파편화로 접근 어려움 + 투자 절차를 모름
- 시장 지형: 뱅카우·핀돈·소유·카사 직접 열람 경험. 카사는 서비스 종료. 뱅카우가 상대적으로 잘 만듦(실물 고기 수령 옵션, 질병 알림 존재)
- 법제화 일정: 토큰증권 2027-02-04 시행 (팀 리서치 문서로 확인, 흐릿→승격) — 미개발 시장
- (H2 승격) 입문자용 친화 화면·챗에도 권유·보장·예측 차단 필터가 예외 없이 적용되어야 함
- (H4 승격) 빈 검색창 문제 — 입문자는 뭘 물을지 모름 → 예시 질문 칩·추천 질문·가이드 흐름 필수
- (H5 승격) 접근성(쉬운 언어·용어 풀이) = "진입장벽 완화" 심사 어필의 일부로 명시 포장

## Planning Handoff

### 문제 재정의 (before → after)

- **Before (seed)**: 입문자가 많아질 테니, 메인 화면에 AI 검색창 + 친화적 설명 + 카테고리 분기를 만들자.
- **After**: 조각투자 입문자는 정보가 아니라 **판단 기준이 없다**. 뭘 확인해야 하는지 모르고, 주식과 다른 라이프사이클(청약 진입·매각 지연)에 당황하며, 실물 소멸·손상이라는 1차 공포를 갖고, 사건·공시가 상품과 분리된 게시판에 흩어져 직접 대조해야 한다. JeomJeom은 "확인해야 할 것"을 AI가 스캐폴딩하고 각 항목에 공공 원장 대조 실측을 붙여, '진입장벽 완화'를 검증 가능한 형태로 구현한다. 등급·권유는 없으며, 친화적 화면을 포함한 모든 표면에 스파인 필터가 예외 없이 적용된다.

### 가정 목록 (구현·검증 체크리스트로 이월)

1. [가정] 조각투자 입문자 증가 전제 — 통계 확보 전까지 미검증 (H1 research 진행 중)
2. [가정] '진입장벽 완화'가 심사 어필 축 — 공모전 페이지 원문으로 확인 예정 (P1)
