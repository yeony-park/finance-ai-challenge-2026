## 제품 한 문장

조각투자 입문자가 "뭘 확인해야 하는지"를 AI 안내로 배우고, 각 확인 항목에서 공시-공공원장 대조 **실측**을 보게 하는 플랫폼 — 등급·추천 없이, 근거가 없으면 "대조 불가"라고 답한다.

## 구속 결정 (2026-08-15 오너 합의, 근거는 PRD)

1. 검증 엔진(공시·공공데이터 대조)은 특정 카테고리 소유가 아니라 **전 카테고리 하위의 공통 기반**이다.
2. 공통 명세는 오너 담당, **카테고리 특화 구현은 각 담당자**: 부동산=문수 · 한우=원준 · 한돈=연정 · 미술품=현석.
3. **4개 카테고리 균등** — 셸·엔진 인터페이스에서 특정 카테고리를 특별 취급하지 않는다. 데이터 깊이 차이는 층별 지원 선언으로 정직하게 표기한다.
4. 판정 어휘는 2층: 사실 판정 3값 + 근거 상태(→ `02-vocabulary.md`). 투자 등급(해볼 만함/조건부/주의/위험 류)은 채택하지 않는다.
5. 일정 판단은 오너 몫 — 명세는 일정 논리를 담지 않는다 (외부 고정 제약: 제출 2026-09-07 10:00, URL 무중단 09-07 11:00~09-11 23:59).
6. 메인 화면 = AI 대화형 검색(예시 질문 상시 노출) + 조각투자 입문 설명 + 4카테고리 분기 + 방법론 밴드.
7. 표현 경계 필터는 **친화적 표면 포함 전 표면에 예외 없이** 적용된다 (→ `04-expression-rules.md`).
8. 검증 데이터·인용 사실은 사전 생성 캐시에서만 읽는다. AI 추론 호출은 별도 경계로 관리한다 (→ `06-ai-guardrails.md`).

## 구조

```
src/lib/
├─ spine/                    공통 AI 안전 계층 (도메인 무관 — 기존 그대로)
├─ verify/
│  ├─ (core)                 파이프라인·교차검증·판정·리포트·정정·트랙레코드 (기존 그대로)
│  └─ contract/              ★ 신설 — 카테고리 계약 타입 + 어휘 프로젝션 (M1)
│     categories/            M2+ — 카테고리별 어댑터·프로파일 물리 분리 (담당자 영역)
└─ app/                      M2+ — 입문자 메인·카테고리 착지·리포트
```

M1은 **기존 파일 무수정·순수 추가**만 한다. 기존 `adapters/`·`parse/profiles` 의 물리적 `categories/` 재배치는 M2+에서 담당자 합의 후 진행한다.
