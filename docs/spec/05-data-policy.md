# 데이터 정책 (위반 금지)

> **상태: v1-draft (팀 리뷰 요청)** · 기존 정책 계승: `CLAUDE.md` "데이터 정책" 절 · 집행 장치: `src/lib/verify/report/mask.ts`·`residual.ts` + 익명화 게이트 테스트 · 신호등 원전: pig-research 계보 리서치 §11 (저작권법 §93, 대법원 2023도17354)

## 1. 마스킹·익명화 (전 카테고리 공통 의무)

- 개인정보 포함 원천(`data/raw/`·`data/snapshots/`·`data/reports/`)은 **로컬 전용**(gitignore). 커밋·배포 대상은 마스킹 완료 산출물뿐.
- 공개 산출물 생성은 반드시 마스킹 2단(마스킹 → 잔존 스캔)을 거치고, **익명화 게이트 테스트(브랜드·실명·주소 누출 0건)를 통과**해야 한다. 이 게이트는 한우 축에서 실제 누출을 잡아낸 이력이 있는 검증된 장치다 — 전 카테고리로 확대한다.
- 공개 슬러그는 중립 id (`cattle-N`·`pig-N`·`art-N`·`re-N` 형식, 기존 `livestock-N`·`real-estate-a`는 유지).
- 자연인 정보는 **아래 예외 목록 외에는** 어떤 표면에도 표기하지 않으며, 예외 여부와 무관하게 농장주명·상세주소·사업자번호 등 비공시 자연인 정보는 **어떤 외부 AI 모델에도** 보내지 않는다.

### 실명 표기 예외 기준 `[팀 결정 대기 — 기본값]`

- 허용: DART 법정 공시로 이미 공개된 **법인 발행인명**, 공시 문서 제목·접수번호.
- 미술품 작가명(자연인): 공개 시장 정보(경매 기록 등)로 이미 공개된 범위에서 **화면 표기만** 허용 — 외부 AI 모델 전송은 불가(기본값). 판정 표시와 결합할 때는 발행사·상품 단위로만 판정을 붙인다 (작가에게 판정이 걸린 것처럼 보이는 배치 금지).
- 불허: 예외 목록 외 자연인 식별 정보, 공시에 없는 내부 정보.
- **허용 실명은 카테고리 디스크립터의 `allowedPublicNames`(실명 + 공개 근거)로 선언한다** — 익명화 게이트가 참조하는 기계 검증 가능한 allowlist다. 선언 없는 실명은 게이트가 누출로 처리한다.
- 실명 표기 상품에 "원장 불일치"가 공개되는 경우 이의제기 채널(`04-expression-rules.md`) 고지가 필수 전제다.
- 개인 정보주체(자연인)의 정정·삭제 요청 창구를 방법론 페이지에 함께 고지한다 (마스킹 실패 시 대응 경로).

## 2. 라이선스 신호등 게이트 (수집·재표시 공통)

| 등급 | 기준 | 공개 화면 |
|---|---|---|
| Green | 공공누리 1유형·이용제한 없음 명시·법령상 공개 자료 | 허용 |
| Yellow | 이용조건 불명·약관상 권리 유보 (플랫폼 페이지·PDF 재사용 등) | **서면 확인 완료 전 금지** — 원문 링크 + 최소 사실 인용으로 격하 |
| Red | 크롤링 수집물, robots·약관 위반 수집물, 스크린 스크래핑 | 수집 자체 금지 |

- 재표시(화면 렌더링)도 수집과 동일하게 게이트를 적용한다 — "수집은 남이 했으니 괜찮다"는 성립하지 않는다.
- 모든 수집 자산은 메타데이터 필수: `sourceUrl` · `license`(등급+근거) · `method`(official_download/api/manual) · `retrievedAt` · `sha256` (미러: 경락가 CSV 기록 방식, `data/MANIFEST.md`).
- 기존 자산 중 Yellow 미확인분(미술품 플랫폼 유래 데이터 등)은 `07-asset-map.md`에 등급을 명시했다 — 담당자는 게이트 통과 전 공개 화면에 올리지 않는다.

## 3. 제3자 이미지 정책

- **허가 없는 제3자 플랫폼·CDN 호스팅 이미지의 화면 렌더링 금지** (핫링크·프레이밍 포함). 근거: ①저작물 전시·전송권 ②플랫폼 약관 ③타사 CDN 차단 시 심사 기간 화면 깨짐.
- 작품·상품 이미지는 원문 링크 **텍스트**로 제공한다 — 여기서 '원문 링크'는 **해당 상품의 원문 페이지 URL**이며, 이미지 파일 URL 직링크는 불가. 화면 이미지는 자체 제작·허가 확보 자산에 한정.
- 제3자 이미지 URL의 **보존**은 로컬 전용 원천 데이터에 한정한다 — 커밋·배포되는 공개 산출물에는 이미지 URL을 싣지 않거나 비렌더 필드로 격리한다.
- 집행 장치(M2 반영): Next 이미지 원격 패턴 비움 + CSP `img-src 'self' data:` + 공개 데이터 내 이미지 URL 화면 미사용 정적 회귀 테스트.
- 외부 페이지 iframe 임베드 금지 (X-Frame-Options 차단·가용성 의존) — 정적 요약 + 원문 링크로 대체.

## 4. 대화 입력 개인정보 (AI 검색 표면 신설 의무)

- 계정·식별자 비수집. 대화에 개인정보 입력을 요구하지 않는다.
- 입력 로그를 저장하는 경우 개인정보 자동 마스킹 후 저장 — 마스킹 장치는 리포트 경로와 동일한 마스킹 2단(`mask.ts` 계열 + 잔존 스캔)을 재사용한다. 보존 기간 기본값 30일 `[팀 결정 대기]`.
- 사용자 입력이 외부 AI 모델로 전송된다는 사실과 한계를 개인정보 처리방침으로 화면 고지.
- 스파인 입력 스크리닝의 PII 조회 차단은 "묻는" 것의 차단이다 — "제공된" 개인정보의 보호(본 절)와 별개로 둘 다 적용한다.

## 5. 신선도 표기

- 모든 화면 수치·근거에 `as_of`·`fetched_at` 병기 (`03-evidence-structure.md`).
- 제출 동결 기간 정책 `[팀 결정 대기 — 기본값]`: 코드·IA 동결 + 게이트(익명화·테스트) 통과 데이터 갱신은 지속. 갱신이 멈추더라도 기준일 표기가 정직하면 원칙 위반이 아니다.
