# 페이즈 계획 v2 — 2026-08-07 기준 재조정

> 검토서(8/2) 원계획을 오늘 날짜·검증 결과(Stream 5~8)·기구현 자산(신뢰 스파인) 반영해 재조정.
> 마감 역산: **9/5(토) 제출 목표**(공식 마감 9/7 10:00의 이틀 버퍼) · 9/7~9/11 심사 접속 기간 무중단.

## 원계획 대비 변경 요지

1. **신뢰 스파인이 이미 구현돼 있음**(`src/lib/spine/` — 가드레일·출처 강제 RAG·HITL·레이트리밋·레드팀 러너 + 테스트) → 검토서 원계획엔 없던 자산. Phase 2~3의 기반 공사가 절약됨
2. **AI Hub 580 승인 리드타임이 크리티컬 패스** → Phase 0에 "오늘 신청"으로 승격, 승인 지연 시 폴백(자체 골드셋 선라벨링) 명시
3. **diff 기준선을 별표15로 교정**(공정위 아님) + 크롤링 수칙(Stream 8)을 Phase 1 수집기 요구사항에 내장
4. **3층 입력 UX**(프리로드/자동 매칭/업로드 폴백)를 Phase 별로 분리 — 프리로드가 필수, 자동 매칭은 차별화 데모, 업로드는 안전망
5. 학습(분류기)은 AI Hub 데이터 한정, 크롤링 약관은 추론 전용 (법적 회색지대 회피)

## Phase 2 — 분석 코어 (8/15~8/22)

| 작업 | 내용 | 완료 기준 |
|---|---|---|
| LLM 필드 추출 | 스키마 기반 전수 추출, 신뢰 스파인 경유(출처 강제) | 골드셋 EM/F1 측정 시작 |
| 별표15 diff 엔진 | 조항 정렬 → 편차 탐지 → 소비자 불리 방향 판정 | 가상 변형 약관 테스트셋에서 P/R 확인 |
| 불리조항 분류기 | AI Hub 라벨 학습(승인 시) / 폴백: 자체 골드셋 + LLM few-shot | 분류 F1 측정 시작 |
| 심결례·분쟁조정 RAG | 공정위 결정문·금감원 사례 색인, 약관규제법 6~14조 유형 매핑(+15·16조 보조 룰) | 조항 → "유형+유사 사례 n건" 반환 |
| 등급화 규칙 | 근거 개수·편차 정도 → 참고/주의/경고. 규칙 명문화 | 등급 결정 로직 문서+테스트 |

**게이트**: 샘플 상품 1개의 전 파이프라인 통과(업로드 없이 프리로드→분석→근거 카드). AI Hub 미승인 시 분류기는 few-shot 폴백으로 강행.
