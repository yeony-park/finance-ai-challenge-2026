# Stream 8 — 법적 리스크 검증: 공시실 약관 크롤링·이용의 적법성

> 2026-08-07 리서치(2개 병렬 에이전트: ① 크롤링 행위 적법성 ② 수집물 이용·재표시 적법성).
> **본 문서는 판례·법령 기반 리스크 평가이며 법률 자문이 아니다. 수상 후 상용화 시점에 정식 자문 필요.**

## Executive Summary

공모전 MVP 시나리오(보험사 공시실의 약관 PDF를 수칙 준수 하에 수집 → 분석·조항 인용·diff 표시)는 **종합 저위험**으로 판단할 근거가 수집됐다. 형사 리스크는 대법원 2021도1533(여기어때 무죄)로 사실상 배제되고, 민사 패소 판례들(잡코리아·야놀자)은 "직접 경쟁사의 차단 우회 + 전량 복제 + 동일 영업 사용" 사안이라 구조가 다르다. 약관이 보험업법 제124조에 따른 **법정 의무 공시 자료**라는 점이 전 쟁점에서 유리하게 작용한다. 유일한 회색지대는 **크롤링한 약관을 분류기 학습에 쓰는 것**(TDM 면책 미입법)인데, 우리 설계상 학습은 라이선스가 명시된 AI Hub 580으로 하고 크롤링 약관은 추론(분석) 입력에만 쓰면 이 리스크도 우회된다.

## 1. 크롤링 행위 적법성 (쟁점별)

| 쟁점 | 위험도 | 핵심 근거 |
|---|---|---|
| 정보통신망법 침입죄 | **저** | 대법원 2022.5.12. 선고 **2021도1533**(여기어때 vs 야놀자): 보호조치 없는 공개 페이지의 크롤링은 접근권한 없는 침입 아님. 단 봇 차단 우회(IP 로테이션·UA 위장)는 판단을 뒤집을 수 있음 |
| 부경법 (카)목 데이터 부정사용 | **저** | 보호 대상은 "특정인·특정 다수 제공" 데이터 — 불특정 공중에 공개된 공시자료는 문언상 요건 불충족 (김·장 해설) |
| 부경법 (파)목 성과물 도용 | **저~중** | 패소 사례(야놀자 민사 1심 2018가합508729, 10억 배상·항소기각 / 잡코리아 2015가합517982)는 경쟁사 간 전량 복제 사안. 약관은 "상당한 투자의 성과"가 아닌 법정 공시 의무 이행물 + 비경쟁 관계라 요건 충족 곤란. 다만 보충적 일반조항 특성상 예측가능성 낮음 |
| 저작권법 제93조 DB권 | **중** | 잡코리아 사건(서울고법 2016나2019365, 대법 심리불속행 확정)은 반복·체계적 전량 복제로 침해 인정. **전체 미러링을 피하고 필요 약관만 선별 수집**하면 "상당한 부분" 요건 회피 가능 |
| robots.txt | 참고 요소 | 그 자체 법적 구속력 없음. 단 판례가 위법성 판단의 정황으로 사용(사람인 사건) — **Disallow 사이트 제외, Allow(삼성화재 확인) 위주** |
| 업무방해 | **저** | 2021도1533: 1,594만 회 접속도 무죄(정상 요청 + 장애 미발생). MVP 수준(수십~수백 건 저빈도)은 문제 소지 없음 |
| 공시자료 특수성 | 유리 | 보험업법 제124조·감독규정 7장 의무 공시 + Open DART가 공시데이터 재활용을 제도적으로 장려하는 관행. 단 "공시 = 크롤링 허용"의 명시 판례는 없음(유리한 정황이지 면책 아님) |

## 2. 수집한 약관의 이용·재표시 적법성 (이용 형태별)

| 이용 형태 | 위험도 | 핵심 근거 |
|---|---|---|
| ① LLM 분석 입력 (내부 처리) | **저** | 공중 제공 아닌 내부 이용, 창작성 낮은 기능적 문서, 시장 대체 없음. 문체부 2026.2 「AI 학습 공정이용 안내서」 4요소상 유리 |
| ② 조항 원문 하이라이트·인용 | **저** (전문 통째 게시 시 중) | 저작권법 제28조 정당한 인용 — "분석 결과 主 + 원문 스니펫 從 + 출처 표시"(대법원 97도2227 기준). 약관은 판매 시장이 없어 수요 대체 관념 자체가 성립 곤란 |
| ③ 표준약관 diff 표시 | **저** | 표준약관(금감원 세칙 별표15)은 행정규칙 별표로 저작권법 제7조 비보호 저작물 해당 소지 큼 + 창작성 희박. diff는 변형적 이용 |
| ④ 크롤링 약관의 분류기 학습 | **중** | TDM 면책 **2026.8 현재 미입법**(21대 폐기, 22대 계류), 리딩 판례 부재(방송3사 vs 네이버 2025.1·vs 오픈AI 2026.2 소송 진행 중). 단 비생성·비재현 분류기 + 기능적 문서라 방어 여지 큼 |

**약관의 저작물성 자체**: 정면 판례 미발견. 표준약관 골격 + 감독당국 심사 + 표현 선택 폭 협소 → 전형적 기능적 저작물로 조항 단위 창작성 인정 가능성 낮음(대법원 2009도291 기준). 단 회사별 특약·안내문구 일부는 창작성 여지 있어 "전면 비보호" 단정은 금물.

**공모전 맥락**: 비영리·심사용은 공정이용 제1·4요소에서 유리하게 작용하나 단독 면책 사유는 아님(대법원 2021다272001 — 공정이용 첫 대법 판결, 시험문제 게시 부정).

## 3. 종합 설계 결정 (리스크 통합 회피)

**핵심 회피 설계**: ④(학습)의 중위험은 **분류기 학습을 AI Hub 580(라이선스에 학습·서비스 활용 명시, Stream 5)으로 수행**하고, **크롤링 약관은 추론(분석) 입력 + 조항 인용에만 사용**하면 구조적으로 해소된다. 크롤링 약관을 학습 코퍼스에 넣지 않는 것을 기본 원칙으로.

### 실무 수칙 (파이프라인 요구사항)

1. **robots.txt Disallow 사이트 수집 제외** — Disallow인 곳(생보협회 등)은 수동 다운로드 또는 다른 소스로 대체. 수집 시점의 robots.txt 스냅숏 보관
2. **차단 우회 금지** — IP 로테이션·UA 위장·CAPTCHA 우회 금지. UA에 봇 신원·연락처 명시
3. **저부하 수집** — 요청 간 1~3초 딜레이, 순차(비병렬), 사이트당 일 1회 이하 배치, If-Modified-Since 캐싱
4. **필요 최소 수집** — MVP 대상 상품군 약관만 선별. 사이트 전체 미러링 금지
5. **재배포 금지** — PDF 원본 열람·다운로드 기능 제공하지 않음. 원 공시실 링크 병기로 대체
6. **인용 규격** — 화면 표시는 조항 단위 스니펫 + "○○보험 △△약관(2025.4. 개정판, 출처: ○○보험 상품공시실)" 형식 출처 표시. 主(분석)/從(원문) 관계 유지 — "약관 뷰어"가 되지 않게
7. **diff 기준선은 표준약관(별표15)** — 법적 부담 최소 텍스트. 회사 고유 조항만 스니펫 인용
8. **각사 이용약관 확인** — 자동수집 금지 조항 존재 시 해당 사이트 제외(계약 책임은 저작권과 별개 벡터)
9. **수집 로그 보존** — 시점·빈도·robots 상태 기록으로 "정상적·비침해적 수집" 사후 입증 체계

## 4. 기획서 반영

- **법적 검토 문단을 기획서에 명시** — "① 법정 공시자료 대상, ② 대법원 2021도1533 기준 준수 수집, ③ 제28조 요건을 충족하는 조항 인용, ④ 학습은 AI Hub 라이선스 데이터로 한정, ⑤ 표준약관은 제7조 비보호 소지" 논리 구조. 주최가 금융보안원인 만큼 컴플라이언스 선제 검토는 가점 요인
