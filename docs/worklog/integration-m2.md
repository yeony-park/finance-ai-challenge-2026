## T2 — 표현 필터 확장 + 레드팀 셋 v2 (2026-08-16)

통과, 도메인 필터 테스트 확장(차단 9·통과 11 케이스 추가) 전건 그린, notices 회귀 유지.

**트레이드오프** — (a) `aggregate-score`의 등급·점수 매칭은 접두어(신뢰/안전/투자 등)로
