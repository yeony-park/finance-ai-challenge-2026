# 프론트엔드 검토 및 최적화 — 2026-09-06

## 검토 범위

사용자가 제공한 과거 해커톤 프론트엔드 리뷰를 참고해 타입 안전성, API 경계, 하드코딩, 중복 계산, 컴포넌트와 상태 관리, 지도 상호작용을 검토했다. 참고 문서의 지적을 현재 프로젝트의 결함으로 간주하지 않고 실제 코드를 확인했다. 서브에이전트 3개가 각각 응답 계약, 성능, 지도·상호작용을 검토하고 수정했다.

이번 작업 전부터 존재하던 화면 디자인 변경은 유지했다. 아래 목록은 이번 검토에서 추가로 발견하고 수정한 내용이다.

## 성능 측정의 범위

서브에이전트가 로컬에서 상태 탭 4개의 집계를 100회 반복한 측정값:

| 검색 조건 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 검색어 없음 | 약 163ms | 약 134ms |
| 김환기 | 약 1,643ms | 약 133ms |
| 2024년 청산 | 약 1,707ms | 약 131ms |

집계 함수의 반복 실행 비용을 측정한 값이다. 전체 페이지 로딩 시간이나 사용자 환경에서의 응답 시간 개선율로 해석하지 않는다. 합성 미술품 JSON은 서버에서 사용하므로 이번 변경을 클라이언트 번들 감소로 계산하지 않는다.

## 검증 결과

- `npm run lint`: 통과. 기존 원본 질병 데이터 JavaScript의 미사용 변수 경고 3건은 남아 있다.
- `npm exec tsc -- --noEmit`: 통과.
- `npm run build`: 통과. 사전 지식 자료·AI 요약 검사도 통과.
- `npm exec vitest -- run --maxWorkers=2`: 188개 테스트 파일 통과, 2,547건 통과, 기존 조건부 건너뜀 30건.
- 기본 동시 실행에서는 검색 오케스트레이션 테스트 1건이 5초 제한을 초과했다. 해당 파일 단독 실행 20건과 동시 실행 수를 줄인 전체 실행에서 통과했다. 테스트 제한 시간을 늘리거나 검증 조건을 약화하지 않았다.
- 브라우저: 홈에서 한돈 검색 결과 3개와 상품 링크, 한우 카드의 `1건`/`37두` 구분, 미술품 루메라 검색 결과 1개와 탭 건수 일치 확인.
- 브라우저: 한돈 질병 지도 핀 선택, Escape 닫기·포커스 복귀, 질병 필터 변경, 요약/질병 탭 재진입 후 마커 표시 확인.

## 남은 검토 항목

합성 미술품 정적 JSON의 진입점에는 `as unknown as SyntheticArtDataset` 단정이 남아 있다. 현재 AI 입력용 스키마는 원본 전체 컬렉션을 다루지 않아 그대로 적용하면 필드가 소실될 수 있다. 정적 데이터의 기존 참조·계산 테스트는 통과했다. 원본 전체를 검증하는 스키마를 별도로 통합하는 작업은 후속 개선 항목이다.

한우 1~8호의 제한된 근거 범위는 화면 최적화와 별개의 데이터 상태다. 현재 승인 공시와 기존 발행 리포트의 연결 조건을 임의로 우회하거나, 미확인 값을 9호 데이터로 채우지 않았다.
