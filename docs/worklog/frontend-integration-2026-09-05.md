# 프론트 통합과 화면 정리 (2026-09-05)

## 통합 브랜치 반영과 공통 화면

**결정과 근거** — 원격 HEAD를 조회해 기본 브랜치가 `integration`임을 확인했다. `feat/integration-front-develop`에서 `git pull --no-rebase --no-edit origin integration`으로 `a41bc1e`를 병합했다. 충돌 20건은 현재 공통 화면 구조와 원격의 데이터·근거 기능을 함께 유지하도록 해결했다. MunSu2001의 `3403e80` 등으로 들어온 부동산 시나리오 13건, 상품 근거 질문, AI 요약을 연결했다. `Su` 브랜치와 비교한 관련 화면·데이터 변경은 이미 통합 브랜치에 포함돼 있어 별도로 중복 이식하지 않았다.

카테고리 검색·상태 필터를 공통 화면에 배치하고 상세 경로를 `/{category}/products/{id}`로 모았다. 이전 `/offers/{id}`와 `/art?product=`는 새 경로로 이동한다. 한돈 API ID `pig-N`은 기존 상세 ID `round-N`에 연결한다. 부동산은 요약·조건·건물·수익/비용·운영 이력·근거의 6개 탭을 사용하며, 한우·한돈·미술품의 고유 분석 항목을 유지한다. 부동산 관심 등록이 저장 목록에 빠지던 부분도 연결했다.

**트레이드오프** — 모든 상품의 탭 이름까지 같게 만들면 자산별 분석 항목이 흐려진다. 목록·상세·탭 이동의 구조와 디자인 토큰을 공유하고 필요한 분석 탭은 자산별로 유지했다. 공통 문서의 `/offers/common/{category}/{product}`는 ID 충돌을 막는 namespace가 필요하므로 호환 경로로 남겼다.

**검증 영향** — 상세 링크·공개 승인 범위·탭별 데이터 보존·검색 필터·관심 목록 테스트를 갱신했다. 공개 승인을 받지 않은 자료는 기존처럼 노출하지 않는다. 원격의 API·근거 검색·AI 요약 검사도 함께 실행했다.

**알려진 한계** — 부동산 투자조건은 실제 판매 상품이 아닌 검토용 시나리오다. 관심 목록에서도 실제 공시 감시 대상으로 표시하지 않는다. 외부 키를 사용하는 라이브 재검증이나 유료 생성 호출은 이번 화면 검증에 포함하지 않았다.

## 스크롤·스타일·문구와 파일 정리

**결정과 근거** — 홈 히어로의 문서 좌표는 레이아웃이 바뀔 때 다시 재고, 스크롤에서는 저장한 좌표를 사용한다. 진행률이 같으면 계산과 CSS 갱신을 생략하고, 모션 축소 설정을 따른다. 검색 요청 교체·닫기·화면 종료 시 이전 요청과 전환 타이머를 취소한다. 컴포넌트의 숫자 글꼴 크기와 지도 색상은 `tokens.css` 변수로 모았다.

[im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 사실 보존과 자연스러운 한국어 원칙을 참고했다. 미술품의 영문 테스트용 분석 설명은 화면에서만 한국어로 바꾸고 원본 수치·근거·AI 요약 입력은 보존한다. 원문 인용은 고쳐 쓰지 않는다.

삭제한 파일은 사용하지 않는 `HeroShards.tsx`와 전용 CSS, 기존 카탈로그와 중복되던 `components/art/SyntheticArtCatalog.tsx`와 전용 CSS, 삭제 상태였던 구형 `OfferTabs.tsx`·`report-catalog.ts`다. 중복 카탈로그의 AI 요약·근거 질문은 기존 미술품 상세에 옮긴 후 제거했다. API 명세, 디자인 시스템, 사용자 흐름, README, AGENTS 지침과 데이터 매니페스트를 갱신했다. `npm ci`에서 발견한 플랫폼별 선택 의존성 누락은 잠금 파일 재생성으로 해결했다.

**트레이드오프** — 스크롤 연출을 유지하면서 불필요한 측정과 갱신을 줄였다. 성능 향상률이나 FPS 수치는 측정하지 않았으므로 제시하지 않는다. 한국어 표시 변환은 현재 승인된 합성 데이터의 문장 형식에 한정되며, 새 형식의 문장은 원문으로 표시된다.

**검증 영향** — 전체 테스트 179파일, 2,425건 통과·30건 건너뜀. lint 오류 0건, 타입 검사와 프로덕션 빌드 통과. 빌드 사전 검사에서 부동산 파생 자료 13건과 AI 요약 34건의 최신 상태를 확인했다. 브라우저에서 홈 스크롤·구간 이동, 부동산 13건 목록·6개 상세 탭·근거 질문 응답·관심 등록/해제, 미술품 AI 요약과 분석 탭, 한돈 공시·질병 탭을 확인했다. 390px 부동산 화면에서 가로 넘침이 없음을 확인했다.

**알려진 한계** — 원본 자료 JS에서 기존 미사용 변수 경고 3건이 남아 있다. 로컬 검증 결과이며 GitHub의 `Verify` 실행 결과를 대신하지 않는다. 작업 전부터 수정돼 있던 한돈 파일 3개와 `Claude outputs/`는 이번 병합 커밋에서 제외한다.
