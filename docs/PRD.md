# DAKER 미술품 조각투자 합성 검토 대시보드 PRD

## 제품 정의

DAKER는 합성 미술품 조각투자 사례를 사용해 공모가격 구성, 비교 근거, 회수 조건과 플랫폼 이력 검토 경험을 제공합니다. 합성 값은 실제 투자 대상이나 추천이 아닙니다.

## 데이터 범위

- 현재 상품: 합성 9건
- 과거 플랫폼 이력: 합성 318건
- 가상 플랫폼·발행사: 각 3곳
- 합성 추상 이미지: 9개
- OpenDART: 서버 전용 기능을 유지하되 합성 상품과 실제 공시를 연결하지 않음

## 요구사항

- 상품·작가·플랫폼·과거 기록을 분리해 탐색합니다.
- 모든 데이터에 합성 표시를 제공합니다.
- 구좌당 공모가 × 구좌 수 = 총 공모금액 관계를 지킵니다.
- 취득가·비용·공모금액과 매각·분배·수익률 계산을 일관되게 유지합니다.
- 기간과 상태 전이를 논리적으로 생성합니다.
- 공개 API는 allowlist DTO만 반환하며 내부 payload와 원격 출처 URL을 반환하지 않습니다.
- OpenDART 인증키는 서버에만 보관합니다.

## 비목표

실제 상품 추천, 개인별 매수·매도 판단, 목표수익률·원금 보장, 실존 작품 감정·진위 판단, 합성 상품과 실제 공시의 연결은 제공하지 않습니다.

## 승인 기준

- lint, typecheck, unit/integration/build 통과
- 합성 source·artifact·Docker 경계 검사 통과
- 실제 원본 identity·URL·payload 0건
- Git/배포 이력과 cache 정리 여부 별도 확인
