# 스트림 4: 공개 금융 데이터·API·기술 자원

> 리서치 에이전트 산출물 (2026-07-31). 주의: 이 스트림의 "주제별 구현 가능성 매핑"은 에이전트가 상정한 7개 유형 기준이며, 공모전 공식 세부 주제 예시 7개와 대체로 겹치지만 1:1은 아님.

## 핵심 요약

- **즉시 발급형 무료 API가 충분히 존재한다.** 금융감독원 금융상품한눈에(예·적금/대출 8종), OpenDART(공시·재무제표), 한국은행 ECOS, KOSIS, 공공데이터포털 금융공공데이터는 모두 개인이 이메일 가입만으로 당일(대부분 즉시~30분 내) 인증키를 받을 수 있고 전부 무료다. 5주 구현 일정에 병목이 없다.
- **공공데이터포털(data.go.kr)이 사실상 허브다.** 금융위 금융공공데이터(기업 재무 4,450만 건), 서민금융진흥원 맞춤대출 상품, K-Startup 사업공고, 기업마당(bizinfo) 지원사업, KISA 피싱 URL·WHOIS까지 한 계정으로 커버된다. 개발계정은 자동승인, 일 1,000~10,000건 트래픽.
- **오픈뱅킹·마이데이터 실데이터는 개인 참가자가 쓸 수 없다.** 금융결제원 오픈뱅킹은 테스트(샌드박스)까지만 가능하고 실서비스는 기관 승인 대상. 금융보안원 마이데이터 테스트베드는 개인에게 API 규격 열람만 허용. MVP에서는 모의 계좌 데이터 또는 AI Hub 금융 합성 데이터로 대체하는 전략이 필수다.
- **AI Hub '금융 합성 데이터'가 마이데이터 대체재로 유력하다.** 카드·신용·CB·기업정보 등 12종 정형 데이터 약 1.6억 레코드, 회원가입+승인 후 다운로드.
- **보이스피싱 분야는 '정제된 공개 데이터셋'이 공백이다.** 금감원 보이스피싱지킴이 체험관의 사기범 음성('그놈/바로 이 목소리')과 시나리오는 웹 게시물 형태로 소량. 금감원 보유 신고 음성 2.5만 건은 기관 협약용으로 비공개. AI Hub에 보이스피싱 전용 음성 데이터셋 확인 안 됨(미확인). 학술 데이터셋(KorCCVid)과 KISA 피싱 URL 파일이 부분 대안.
- **증권 데이터는 KIS Developers(한국투자증권)가 개인에게 가장 현실적.** 계좌만 있으면 10분 내 앱키 발급, 모의투자 무료. KRX Open API는 API별 이용신청 + 상업적 이용 제한.
- **한국어 금융 NLP 자원이 성숙.** KRX 금융 언어모델 경진대회(2024) 공개 모델 600+ (HuggingFace), KB-ALBERT/KB-BERT, AI Hub 금융 말뭉치·기계독해, FINE 포털 표준약관·금융꿀팁 등 RAG 소스 풍부.

### 3. 거시·통계
- **한국은행 ECOS API** (ecos.bok.or.kr/api): 기준금리·환율·물가·가계신용 시계열. 무료, 즉시 발급.
- **KOSIS OpenAPI** (kosis.kr/openapi): 국가통계 전반. 무료, 자동승인.

### 4. 오픈뱅킹·마이데이터 — 제약 큼 ⚠
- 금융결제원 오픈뱅킹: 개발자사이트 간편가입 → **테스트베드까지만** (잔액·거래내역·이체 API 시험). 실서비스는 기업 승인 대상.
- 금융보안원 마이데이터 테스트베드: 기관 대상. 개인은 **표준 API 규격 열람만**.
- 대안: ① AI Hub 금융 합성 데이터로 모의 계좌·카드 구성 ② 마이데이터 표준 규격대로 목(mock) 서버 구현("규격 준수" 어필) ③ 데모용 가상 사용자. (공모전 규정상 모의 데이터 허용 여부는 명시 규정 미확인)

### 5. 보이스피싱·금융사기
- 금감원 보이스피싱지킴이: 음성+시나리오 (데모 입력용).
- 경찰청 사이버캅: 전화·계좌 사기신고 조회 가능하나 **공식 API 없음** (비공식 스크립트만, 연동 비권장).
- KISA 보호나라: 카톡 채널 확인서비스(API 아님).
- AI Hub 보이스피싱 음성 데이터셋: 확인 안 됨(미확인). KorCCVid 학술 데이터셋(배포 경로·라이선스 미확인).

### 6. AI Hub (aihub.or.kr) — 내국인 가입+승인, 무료

| 데이터셋 | 내용 |
|---|---|
| 금융 합성 데이터 (71792) | 카드·신용·CB·기업 등 12종 정형, ~1.6억 레코드 |
| 금융·법률 문서 기계독해 (71610) | 금융 문서 MRC QA |
| 금융 다국어 병렬 말뭉치 (71782) | 보고서·계약·법령 텍스트 |
| 민원(콜센터) QA (98) | QA 110만 쌍 + 음성 440시간 (금융·보험 상담 포함) |

### 7. 증권·시세
- **KIS Developers** (apiportal.koreainvestment.com): 국내외 시세·주문·계좌 REST/WebSocket. 한투 계좌 → 앱키 ~10분. 모의투자 무료. 개인 최적.
- KRX Open API (openapi.krx.co.kr): 인증키+API별 신청, **상업적 이용 금지**. pykrx는 약관·안정성 리스크.

### 8. 한국어 금융 NLP·LLM
- KRX 금융 언어모델 경진대회(2024): 600+ 모델 HuggingFace 공개, KRX-Bench, ₩ON 모델(ACL 2025).
- KB-ALBERT/KB-BERT: KB 공개 금융 특화 PLM.
- RAG 소스: FINE 표준약관·금융꿀팁, 보이스피싱 사례·시나리오, K-Startup/bizinfo 공고문, OpenDART 공시원문, 소진공 정책자금 공고, 금융위·금감원 보도자료.

## 주제 유형별 구현 가능성 (에이전트 상정 7유형)

1. **보이스피싱·사기 예방**: 보이스피싱지킴이 음성·시나리오 + AI Hub 콜센터 음성 + KISA 피싱 URL·WHOIS + LLM 판별. 공백: 실시간 사기번호 API, 대규모 라벨 데이터 → LLM few-shot + 자체 시나리오로 우회. 실현성 **중상**.
2. **서민·취약계층 정책금융 추천**: 서금원 맞춤대출 API + 금융상품한눈에 + FINE RAG + ECOS. 공백: 개인 실데이터 → 자가입력+합성. 실현성 **상**.
3. **소상공인 정책자금 내비게이션**: bizinfo + K-Startup + 소진공 공고 RAG + 상권 API + KOSIS. 공고문 비정형 → LLM 파싱이 오히려 AI 포인트. 실현성 **상**.
4. **금융상품 비교·약관 해설**: 금융상품한눈에 8종 + 표준약관 RAG + 공개 금융 LLM. 실현성 **상** (가장 안전).
5. **자산관리·금융교육 (청년/시니어)**: AI Hub 합성 데이터 + ECOS/KOSIS + 금융상품한눈에 + 마이데이터 규격 목 서버. 실계좌 연동 불가가 제약. 실현성 **중상**.
6. **공시·투자정보 AI 분석**: OpenDART + KIS + 금융위 기업재무 + 공개 모델. 실현성 **상**.
7. **창업·혁신기업 금융 매칭**: K-Startup + bizinfo + 벤처확인 공시 + 기업기본정보. 보증기관 상품 API 미확인 → 공고 RAG 보완. 실현성 **중상**.

→ 2·3·4·6이 "공개 데이터만으로 완결"되는 안전 지대. 1·5는 데이터 공백을 합성·생성으로 우회하는 설계 자체가 차별화 포인트.
