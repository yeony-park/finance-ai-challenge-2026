## 1. R1 — 유동성·회수 실태

### 판정: "팔기 어렵다" = **참**

네 겹의 봉쇄:

1. **제도적 봉쇄** — 미술품·한우 등 **투자계약증권은 2차 거래 원칙 금지** `[교차]`
2. **인프라 부재** — 제도권 유통플랫폼 **8/8 현재 0곳 가동**. 2026-02-13 KDX·NXT 예비인가는 **신탁수익증권 전용** `[1차: FSC]`
3. **유동성 실종** — 거래 기능이 도는 뮤직카우조차 매도 754주 : 매수 7주 `[단일]`
4. **발행자 소멸** — 1세대 6개사 중 카사·펀블 폐업, 갤럭시아에프앤·에이판다 피인수 `[교차]`

### 중요한 구분 — 과장하면 안 되는 지점

폐업 ≠ 원금 소실. 신탁 구조라 기초자산은 남고 매각 대금이 지분율대로 분배된다. 카사는 과거 매각에서 +26%, 서초 지웰타워 누적 +25%(세전)도 냈다. **"못 판다"는 참이지만 "돈을 떼인다"는 확인되지 않았다.** 이 구분을 흐리면 우리 서비스가 과장 마케팅이 된다. `[추론]`

### 소비자가 다친 지점

**살 때가 아니다** — 한우는 8연속 완판, 한돈은 3회 연속 280~350% 초과청약. 진입 마찰은 오히려 낮다.
**보유 중 + 팔 때다** — 뮤직카우 배당 연 22.7%→1%대, 시세 -79%. 알아차렸을 때 팔 수단이 없다.
→ **"관찰은 되는데 행동할 수단이 없는 상태"**가 실제 피해 형태다. `[추론]`

### 확인 실패
펀블 공매 낙찰가·투자자 실제 회수율 / 카사 최종 회수율 / 금감원 민원·분쟁조정 통계 / 플랫폼별 거래량 데이터

### ⚠️ 데이터 조달 경로 정정 — 주제 정의 문서 수정 필요

**OpenDART "증권신고서 주요정보" 구조화 API 6종(지분·채무·증권예탁·합병·교환이전·분할)에 투자계약증권·수익증권이 없다.** 정형 JSON 수집 설계는 그대로는 실패한다. `[1차: opendart.fss.or.kr]`

**우회 경로 (검증됨)**:
1. 공시검색 API `list.json`에서 `pblntf_detail_ty` = **C005**(증권신고 기타) · **C010**(소액공모 기타)로 목록 수집
2. 원문 `document.xml` 직접 파싱
3. 2026-07-28을 분기점으로 C010 → C005 이동을 전제로 파이프라인 설계

→ 작업량은 늘지만 막힌 건 아니다. 오히려 **"LLM 비정형 추출"이 선택이 아닌 필수**가 되어 기획서 5번(생성형 AI 역할) 논거가 강해진다. `[추론]`

## 6. 종합 — 세 갈래가 한 점에서 만난다

IDI에서 갈라졌던 두 제품 (A) 공모가 검증 / (B) 실물 가시화, 그리고 R1에서 부상한 (C) 출구·보유 리스크가 **뱅카우 9호에서 하나로 합쳐진다.**

- (B)의 재해석: 우리는 실물을 **보여주지** 않는다. 발행사가 이미 보여준다(R4). 우리는 **보여준 것이 진짜인지 공공 데이터로 대조**한다 — 증권신고서의 개체 이력번호 ↔ 축산물이력제
- (A)의 실행: 취득비·사료비 산출근거 ↔ 축산물품질평가원 경락가 / 카사 공모가·매각가 ↔ 국토부 실거래가(사후 검증)
- (C)의 실행: 청약 미달·자기인수 이력(8-2호), 폐사 수시공시 이행 여부(핀돈), 청산 지연

**한 줄 정의 후보**: *"발행사가 공시한 것과 공공 데이터가 일치하는지 대조하는 독립 검증 레이어"*

R4의 결론과 정확히 맞물린다 — **"발행사가 스스로 보여주는 정보는 이미 충분하다. 없는 것은 그것을 대조할 제3자다."**
