## 1. 축산물이력제 — ① 실재성 층위

**축산물품질평가원_축산물통합이력정보** (공공데이터포털 15058923)

| 항목 | 확인 내용 |
|---|---|
| 제공기관 | 축산물품질평가원 빅데이터분석처 |
| 심의 | **개발단계·운영단계 모두 자동승인** — 대기 없음 |
| 요청 파라미터 | **이력번호(traceNo) 조회 지원** (개체/이력/묶음번호) |
| 응답 항목 | 출생일자·품종·성별 / 농장주소·이동구분 / 도축장명·도축일자·등급명 / 포장처리일자·업소명 |
| 형식 | REST · XML |
| 트래픽 | 개발계정 **일 10,000건**, 운영계정은 활용사례 등록 시 증액 |

관련 데이터셋: **쇠고기이력정보**(15056898) 별도 존재 — 상세 미확인, Phase 1에서 통합이력정보와 비교 후 선택.

**의미**: 뱅카우 9호 신고서에 개체 단위로 공시된 **37두 이력번호를 그대로 조회 키로 쓸 수 있다.** ① 실재성 층위가 설계대로 성립한다. 웹 조회 파싱 폴백은 불필요.

## 2. 축평원 경락가 — ② 가격 층위 (축산)

**축산물품질평가원_축산물등급판정정보** (공공데이터포털 15058822)

| 항목 | 확인 내용 |
|---|---|
| 관련 오퍼레이션 | **축산물 도매시장 소도체 등급별 경락가격정보** / **소도체 1++ 등급 세부경락가격 상세정보** |
| 요청 파라미터 | 경매시작일(startYmd) · 경매종료일(endYmd) · 품종(breedCd) · 성별(sexCd) · 등급구분(qgradeYn) · 가격구분(defectIncludeYn, 결함 포함/제외) |
| 심의 | 개발단계·운영단계 모두 자동승인 |
| 트래픽 | 개발계정 **일 1,000건** — 이력정보(10,000건)보다 빡빡하다. 순회 수집 시 캐싱 전제 |

**의미**: 기간·품종·성별·등급으로 경락가 분포를 뽑을 수 있으므로 뱅카우 9호의 **두당 취득비 218,339,377원 / 37두**를 시장 분포 위에 위치시킬 수 있다. 등급구분 파라미터가 있어 학산농장 **1++ 출현율 57.1%** 주장과 등급별 가격대를 연결하는 경로도 열린다.

⚠️ **일 1,000건 제한**은 Phase 1 수집기 설계에 반영해야 한다 — 일자 순회를 그대로 돌리면 하루치 예산을 금방 태운다.

## 3. 프랩(prap.kr) — 경쟁 지형

| 항목 | 확인 내용 |
|---|---|
| 정체 | ㈜타르트(타르트에이아이) 운영, **대체투자 비교 플랫폼**. TIPS 선정 |
| 규모 | 21개 플랫폼 · 2만+ 상품 통합 비교, 누적 비교검색 150만 건 |
| 앱 | v3.2.0 (2월 27일 업데이트) |
| 제공 기능 | 상품 통합 검색·비교 / 매각 상품 수익률·연환산 수익률 / 모집상태 분류 / **AI 상품설명** / 프랩엑스 양수도 중개 / 내 자산 통합관리 / 신상품·매각 알림 / 최신 뉴스 |
| 공시 원문 검증 | ❌ 없음 |
| 공공데이터 대조 | ❌ 없음 |
| 가격 적정성 판정 | ❌ 없음 |

**의미**: 프랩은 **집계·비교·중개**다. 발행사가 낸 숫자를 모아서 보여주지만 **그 숫자가 사실인지는 묻지 않는다.** 우리의 대조 검증 레이어와 층위가 다르다 — 오히려 "비교는 이미 있는데 검증이 없다"는 기획서 논거의 실증 사례로 쓸 수 있다.

⚠️ **한계**: 앱을 설치해 내부 화면을 직접 확인하지는 못했다. 위 판정은 **랜딩 페이지·앱스토어 설명·보도자료** 기준이다. 다만 검증 기능이 있다면 마케팅에서 빠질 이유가 없는 차별점이므로, 미보유 판정의 신뢰도는 높다고 본다. 팀원 중 앱 설치 가능자가 있으면 교차 확인 권장.

## Phase 1로 넘기는 것

1. **서비스키 실발급 + 호출 테스트** — 위 판정은 전부 문서 기준이다. 뱅카우 9호 37두 이력번호로 실제 응답이 오는지가 진짜 게이트다. **Phase 1 첫 작업.**
2. 쇠고기이력정보(15056898) vs 축산물통합이력정보(15058923) 중 어느 쪽이 개체 조회에 적합한지 비교
3. 경락가 API 일 1,000건 제한에 맞춘 수집·캐싱 전략
4. 프랩 앱 내부 화면 교차 확인 (선택)
