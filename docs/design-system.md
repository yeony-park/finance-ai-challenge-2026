# JeomJeom 디자인 시스템

이 문서는 모든 팀원이 같은 화면 밀도와 시각 언어를 사용하기 위한 공통 기준이다. 제공된 `design.md`의 HP식 카탈로그 원칙을 JeomJeom에 맞게 적용하되, HP 전용 서체·워드마크·제품 이미지는 복제하지 않는다.

## 한 문장 원칙

흰색 바탕과 연회색 섹션을 번갈아 사용하고, `#024ad8` 블루는 행동과 활성 상태에만 제한적으로 사용한다.

## 타이포그래피

공통 화면에서는 아래 네 단계만 먼저 사용한다.

| 역할 | 공용 클래스 | 데스크톱 | 모바일 | 굵기 | 행간 | 용도 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| title | `.type-title` | 44px | 36px | 500 | 1.0 | 자산 페이지의 `h1` |
| subtitle | `.type-subtitle` | 24px | 24px | 500 | 1.17 | 카드·섹션의 `h2` |
| main-text | `.type-main-text` | 16px | 16px | 400 | 1.4 | 핵심 설명과 본문 |
| sub-text | `.type-sub-text` | 14px | 14px | 400 | 1.5 | 보조 설명과 메타데이터 |

- 홈의 첫 화면 제목만 마케팅용 display 예외로 데스크톱 72px, 모바일 40px을 사용한다.
- 제목은 500 굵기를 유지한다. 강조가 필요해도 700 이상으로 올리지 않는다.
- 버튼 외에는 자간을 넓히거나 영문 대문자 변환을 사용하지 않는다.
- 기본 서체는 Apple 시스템 서체를 우선하고 `Apple SD Gothic Neo → Noto Sans KR → Segoe UI` 순서로 보완한다. HP 전용 Forma DJR Micro는 사용하지 않는다.

새 UI에서는 숫자를 직접 쓰지 말고 전역 토큰을 사용한다.

```css
.example-title {
  font-size: var(--type-title-size);
  line-height: var(--type-title-line);
}
```

```tsx
<h1 className="type-title">페이지 제목</h1>
<h2 className="type-subtitle">섹션 제목</h2>
<p className="type-main-text">핵심 설명</p>
<p className="type-sub-text">보조 설명</p>
```

## 컬러

| 토큰 | 값 | 사용 |
| --- | --- | --- |
| `--color-primary` | `#024ad8` | 기본 CTA, 링크, 활성 내비게이션, 핵심 아이콘 |
| `--color-primary-bright` | `#296ef9` | 어두운 배경 위의 블루 강조 |
| `--color-primary-deep` | `#0e3191` | CTA 눌림·강조 상태 |
| `--color-primary-soft` | `#c9e0fc` | 선택 칩과 Copilot 보조 면 |
| `--color-canvas` | `#ffffff` | 기본 페이지와 카드 배경 |
| `--color-cloud` | `#f7f7f7` | 교차 섹션과 보조 카드 배경 |
| `--color-fog` | `#e8e8e8` | 구분선과 강한 보조 면 |
| `--color-ink` | `#1a1a1a` | 제목·기본 텍스트·어두운 푸터 |
| `--color-charcoal` | `#3d3d3d` | 본문과 설명 |
| `--color-graphite` | `#636363` | 작은 메타데이터와 주석 |

### 키 컬러 규칙

1. 한 화면에서 블루 강조는 핵심 CTA와 활성·링크를 중심으로 사용한다.
2. 긴 본문 전체나 큰 섹션 배경을 블루로 채우지 않는다.
3. 기본 본문은 `--color-ink` 또는 `--color-charcoal`을 사용한다.
4. 확인·대조 필요·미확인 상태색은 의미 전달용이다. 키 컬러 대신 사용하거나 색만으로 상태를 전달하지 않는다.
5. 흰색 → cloud → 흰색 순서로 섹션 리듬을 만들고, 페이지 끝은 ink 푸터로 닫는다.

## 간격·형태·깊이

- 간격 기본 단위: 8px
- 주요 섹션 상하 여백: 데스크톱 80px, 모바일 48px
- 카드 내부 여백: 24px 또는 32px
- 카드 모서리: `--radius-card` 16px
- 버튼·입력 모서리: `--radius-button` 4px
- 카드 그림자: `--shadow-soft` 한 단계만 사용
- 주요 컨테이너 최대 너비: 1366px

버튼을 알약 형태로 만들지 않는다. 카드와 컨테이너는 16px로 부드럽게, 클릭 요소는 4px로 각지게 구분한다.

## 장식 규칙

- 홈 hero는 텍스트와 여백 중심으로 구성하고 파란 사선 장식을 사용하지 않는다.
- 카드 안에 반복 장식을 넣지 않는다.
- 프로젝트 로고와 이미지는 JeomJeom 전용 자산만 사용한다.

## 페이지 작성 규칙

각 담당자는 자신의 `page.tsx` 안에 있는 `여기에 … 넣어주세요.` 문구를 실제 내용으로 교체한다.

- `title`: 해당 자산 페이지 이름을 유지하거나 팀 합의 후 변경한다.
- `description`: 페이지의 한 문장 가치 설명으로 교체한다.
- `metrics`: 실제 연결 전에는 `입력 대기`, `미확인`, `연결 대기` 상태를 유지한다.
- `evidence`: 출처, 기준일, 상태를 확인한 뒤에만 `verified`로 바꾼다.
- `workflow`: 실제 사용자가 밟는 순서로 작성한다.
- 돼지 페이지의 `copilot`: 질문과 응답을 근거 연결형 문장으로 작성하며 투자 결론을 생성하지 않는다.

공통 스타일 변경이 필요하면 먼저 팀에 공유하고, 개별 자산의 색상 테마를 추가하지 않는다.
