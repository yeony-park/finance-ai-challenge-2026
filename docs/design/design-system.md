# JeomJeom 디자인 시스템 (통합판)

> 원전: main 계보 `docs/design-system.md` (2026-08 확정, #024ad8 단일 블루). 이 문서는 그 기준을
> integration 셸 현실에 맞게 이관한 통합판이다. 팀원이 카테고리 착지의 `custom` 슬롯을 채울 때도
> 이 기준을 따른다.

## 두 표면 정책 (의도된 seam)

| 표면 | 토큰 | 상태 |
|---|---|---|
| 신규 표면 — 홈(`/`)·카테고리 착지(`/cattle` 등)·`/offers` 목록 | `--jj-*` (이 문서) | M2에서 신규 작성 |
| 기존 표면 — 검증 리포트(`/offers/[id]`)·`/methodology`·사이트 셸 | `--ds-*` (`src/styles/tokens.css`) | 무수정 유지 |

리포트 표면의 `--jj-*` 정합은 후속(M4+) 범위다. 두 체계를 한 컴포넌트에서 섞지 않는다.

## 한 문장 원칙

흰색 바탕과 연회색 섹션을 번갈아 사용하고, `#024ad8` 블루는 행동과 활성 상태에만 제한적으로 사용한다.

## 타이포그래피 (4단계 + 홈 display 예외)

| 역할 | 토큰 | 데스크톱 | 모바일 | 굵기 | 행간 | 용도 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| display | `--jj-type-display-size` | 72px | 40px | 500 | 1.0 | 홈 첫 화면 제목 전용 예외 |
| title | `--jj-type-title-size` | 44px | 36px | 500 | 1.0 | 페이지 `h1` |
| subtitle | `--jj-type-subtitle-size` | 24px | 24px | 500 | 1.17 | 카드·섹션 `h2` |
| main-text | `--jj-type-main-size` | 16px | 16px | 400 | 1.4 | 핵심 설명과 본문 |
| sub-text | `--jj-type-sub-size` | 14px | 14px | 400 | 1.5 | 보조 설명과 메타데이터 |

- 제목은 500 굵기 유지. 강조가 필요해도 700 이상으로 올리지 않는다.
- 버튼 외에는 자간 확대·영문 대문자 변환을 쓰지 않는다.
- 서체는 셸 공통 스택(`--ds-font-sans` = Noto Sans KR 계열)을 그대로 쓴다 — 신규 표면이 서체를
  따로 선언하지 않는다.

## 컬러

| 토큰 | 값 | 사용 |
| --- | --- | --- |
| `--jj-primary` | `#024ad8` | 기본 CTA, 링크, 활성 내비게이션, 핵심 아이콘 |
| `--jj-primary-bright` | `#296ef9` | 어두운 배경 위의 블루 강조 |
| `--jj-primary-deep` | `#0e3191` | CTA 눌림·강조 상태 |
| `--jj-primary-soft` | `#c9e0fc` | 선택 칩과 안내 보조 면 |
| `--jj-canvas` | `#ffffff` | 기본 페이지와 카드 배경 |
| `--jj-cloud` | `#f7f7f7` | 교차 섹션과 보조 카드 배경 |
| `--jj-fog` | `#e8e8e8` | 구분선과 강한 보조 면 |
| `--jj-ink` | `#1a1a1a` | 제목·기본 텍스트·어두운 푸터 |
| `--jj-charcoal` | `#3d3d3d` | 본문과 설명 |
| `--jj-graphite` | `#636363` | 작은 메타데이터와 주석 |

1. 한 화면에서 블루 강조는 핵심 CTA·활성·링크 중심으로만.
2. 긴 본문 전체나 큰 섹션 배경을 블루로 채우지 않는다.
3. 기본 본문은 ink 또는 charcoal.
4. 판정 상태색(`--ds-verdict-*`)은 의미 전달 전용 — 키 컬러 대체 금지, 색만으로 상태 전달 금지.
5. 흰색 → cloud → 흰색 섹션 리듬. 페이지 끝은 ink 푸터(셸 공통)로 닫는다.

## 간격·형태·깊이

- 간격 기본 단위 8px. 주요 섹션 상하 여백 `--jj-section-y`(데스크톱 80px, 모바일 48px).
- 카드 내부 여백 24px 또는 32px. 카드 모서리 `--jj-radius-card` 16px, 버튼·입력 `--jj-radius-button` 4px.
- 그림자는 `--jj-shadow-soft` 한 단계만. 주요 컨테이너 최대 너비 `--jj-maxw` 1366px.
- 버튼을 알약 형태로 만들지 않는다. 카드 16px / 클릭 요소 4px로 구분한다.

## 장식·표현 규칙

- 홈 hero는 텍스트와 여백 중심 — 파란 사선 장식·반복 장식 금지.
- 화면 문안은 `docs/spec/04-expression-rules.md`를 따른다: 시작 촉구 금지, 집계 점수·배지·게이지
  금지, 판정은 건수 나열까지만. 신규 문안은 콘텐츠 모듈(`src/lib/content/`)에 두고 출력 필터 감사
  테스트를 통과해야 한다.
- 리포트 화면의 "UI 자기보고형 금지"(주어=공모·자산) 규칙은 유지된다. 홈·입문 표면의 서비스 서술은
  04의 검증 범위 한정 규칙("검증"=공시-공공원장 대조)과 고정 고지 세트를 따른다.

## 페이지 작성 규칙 (카테고리 담당자)

- 착지 페이지는 공통 셸(`CategoryLanding`)의 계약 슬롯 5종을 유지하고, `custom` 슬롯 안에서만
  자유 구성한다 (`docs/spec/01-category-contract.md`).
- 실데이터 연결 전 상태는 "입력 대기"·"연결 대기"류로 정직 표기한다 — 자리표시 수치 금지.
- 개별 자산의 색상 테마를 추가하지 않는다. 공통 스타일 변경은 팀 공유 후 진행한다.
