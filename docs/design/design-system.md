## 토큰 단일 진실

`src/styles/tokens.css`의 `--ds-*`가 유일한 토큰 원천이다 — 이 문서에 값을 중복 기재하지
않는다(문서-코드 불일치 방지). 새 표면이 색·크기·간격 숫자를 직접 쓰는 것을 금지한다.

## 두 밀도 정책 (같은 토큰, 다른 밀도)

| 표면 | 밀도 | 특징 |
|---|---|---|
| 검증 리포트·방법 (`/{category}/products/[id]`, `/methodology`) | 문서 밀도 | 판정 숫자·개체 표·mono 메타데이터 촘촘히 |
| 홈(`/`)·카테고리 착지(`/cattle` 등) | 안내 밀도 | 같은 토큰으로 여백·행간을 넉넉하게, 카드·질문 중심 |

## 핵심 어휘 (관례로 굳은 사용법)

- **노랑 강조(`--ds-accent`)**: 하이라이트 밑줄(`.mark` — background-image 그라디언트 트릭),
  중요 배지(`accent-soft` 면 + `accent-line` 테두리 + `accent-ink` 글자), 링크 밑줄(2px).
  큰 면을 노랑으로 채우지 않는다.
- **판정 상태색(`--ds-verdict-*`)**: 판정 3값 전용(일치 초록·원장 불일치 빨강·대조 불가 회색).
  브랜드 장식·상태 아닌 정보에 쓰지 않고, 색만으로 의미를 전달하지 않는다.
- **CTA·버튼**: ink 면 + `ink-invert` 글자 + pill 모서리(쉬운 설명 토글·검색 버튼 계열).
  보조 버튼은 `line-strong` 테두리 pill(관심 등록 토글 계열).
- **칩·배지**: pill 또는 `radius-sm`, 선택 상태는 accent 3종 조합(`aria-pressed` 연동).
- **카드**: `line` 테두리 + `radius-lg` + `surface` 면 + `shadow-sm`, hover 시
  `line-strong`+`shadow-md` (offerCard 관례).
- **메타데이터**: `--ds-font-mono` + `text-xs` + `ink-muted` (출처·시각·모드 표기).
- **섹션 리듬**: `bg`(흰) ↔ `bg-muted`(종이톤, `border-block: line`) 교차, 끝은 ink 푸터.
- **타이포**: 제목 `weight-black` + `tracking-tight`, 본문 `leading-relaxed`,
  한국어 개행은 `word-break: keep-all`. display는 홈 hero 전용.
- **아이콘 0 (2026-08-22 오너 결정)**: 전 표면에서 장식·식별 아이콘을 쓰지 않는다.
  재료는 타이포·기하(마름모 등)·사진 3종. 기존 라인아트 모티프는 퇴역(icons.tsx 삭제).
- **조각 클러스터 (홈 히어로 전용)**: 마름모 = `rotate(45deg)` + `overflow: hidden`
  클리핑, 내용·사진은 역회전으로 수평 유지. 상태 문법 — 리포트 공개 중 =
  실선(`line-strong`) + 노랑 하드 엣지(`box-shadow 5px 5px 0 accent-line`) + 선명 사진
  (웜 베일 `rgb(250 249 246 / .55)`), 준비 중 = 점선(`chart-edge`) + grayscale 사진
  (베일 `.82`). 상태는 레지스트리 `preview` 필드에서만 파생. ≤68rem에서 회전 해제 →
  사진 카드 강등. 판정 3색은 히어로에 등장하지 않는다.

## 페이지 작성 규칙 (카테고리 담당자)

- 착지 페이지는 공통 셸(`CategoryLanding`)의 계약 슬롯 5종을 유지하고, `custom` 슬롯 안에서만
  자유 구성한다 (`docs/spec/01-category-contract.md`).
- 실데이터 연결 전 상태는 "선언 대기"·"연결 대기"류로 정직 표기 — 자리표시 수치 금지.
- 개별 자산의 색상 테마를 추가하지 않는다. 공통 토큰 변경은 팀 공유 후 진행한다.
- 화면 문안은 `docs/spec/04-expression-rules.md`를 따르고, 신규 문안은
  `src/lib/content/` 모듈 + 출력 필터 감사 테스트를 거친다.

## 2026-09-05 프론트 통합 기준

- 카테고리는 `CategoryPage`와 `CategoryAnalysisWorkspace`에서 제목·검색·상태 필터를 공유한다.
  부동산도 공통 상태 탭과 `CategoryOfferCard`를 사용하며, 검색과 상태를 함께 적용한다.
  상태 탭은 `전체 · 청약 예정 · 진행 중 · 청약 종료`로 통일한다. 부동산의 거래 중·정산 완료는
  청약 종료에 포함하고 카드에서 세부 상태를 표시한다.
- 한우·한돈·부동산 상세는 `ReportDocument`의 헤더와 탭을 공유한다. 부동산에 정정 감시가 있는 것처럼
  표시하지 않고 상품 조건·건물 정보·수익·비용·운영 이력·근거를 구분한다.
- 본문 landmark는 루트 레이아웃의 `main#content` 하나만 둔다.
- 네 카테고리의 상품 상세 제목은 `--ds-heading-h2`, `--ds-weight-black`, `--ds-leading-tight`를 공유한다.
  미술품의 현재 상품·과거 이력 상세도 같은 기준을 적용한다.
- 컴포넌트의 글자 크기와 색은 `src/styles/tokens.css`를 참조한다. 노란 강조와 Pretendard를 공유하며,
  질병 지도 색상은 `--ds-map-*`, 판정은 `--ds-verdict-*`로 의미를 구분한다.
- 홈 첫 하향 휠은 사진 축소 완료 지점까지 이어지고, 이후에는 기본 브라우저 스크롤을 사용한다.
  위치 측정은 레이아웃이 바뀔 때만 갱신하고,
  같은 진행률의 스타일 쓰기는 생략한다. 동작 줄이기 설정에서는 축소 전환을 생략한다.
- 한국어 문구는 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 사실 보존·번역투 완화 원칙을 참고한다.
  수치·판정·조건은 유지하고, 실제 자료와 합성 시나리오를 명확히 구분한다.
- 제목 위에서 같은 내용을 반복하는 장식용 라벨과 화면 사용법을 설명하는 상투적인 문구는 넣지 않는다.
  제목·필터·상품 정보가 바로 이어지도록 구성하며, 자료 구분·기준일·확인 한계는 필요한 위치에 남긴다.
- AI 요약은 `ProductAiSummary`로 요약 탭의 첫 내용에 배치한다. 요약과 펼친 근거 전체를
  연회색 배경·공통 안쪽 여백으로 묶어 아래 대조 결과와 구분하며, 바깥 테두리는 두지 않는다.
  Copilot은 `ProductCopilot`의 오른쪽 아래 버튼으로 열며, 본문 배치에 영향을 주지 않는다.
  제목·키컬러와 빈 상태를 공유한다. [AI UI 연결 문서](ai-ui-integration.md)를 기준으로 연동한다.

## 페이지 간격·기본 정보 통일 (2026-09-05)

| 용도 | 토큰·컴포넌트 | 기준 |
| --- | --- | --- |
| 탭 아래·상세 본문 간격 | `--ds-content-gap` | 화면 폭에 따라 24–32px |
| 일반 페이지의 주요 섹션 패딩 | `--ds-page-section-gap` | 화면 폭에 따라 32–48px |
| 상품 헤더 기본 정보 | `ProductFacts` | 회색 면, R 12px, 테두리 없음, 2열, 간격 8px, 안쪽 여백 12px/16px |
| 분석 지표 | `ProductMetric` | 회색 면, R 12px, H4 제목, H4·보통 굵기의 값, 보조 설명은 본문 크기 |
| 본문 폭 | `--ds-maxw` + `--ds-gutter` | 최대 1320px 안에 좌우 여백 포함 |

- 공모금액·최소 투자금도 기본 정보 목록 안에 배치한다. 미술품 현재 상품·과거 이력과
  한우·한돈·부동산 헤더가 `ProductFacts`를 공유한다. 수치와 자료 구분은 유지한다.
- AI 요약의 하단 마진과 내부 패딩을 중복해서 넣지 않는다. 다음 섹션이 시작 간격을 정한다.
  좌우 여백은 페이지가 한 번만 적용한다. 요약과 본문의 왼쪽 기준선을 맞춘다.
- 목록 첫 섹션에는 추가 상단 패딩·구분선을 넣지 않는다. 목록 제목과 필터의 간격은
  공통 카테고리 셸이 관리한다. 내부 목록이 하단 패딩을 다시 더하지 않는다.
- 모바일 상품 이미지는 820px 이하에서 한 열·16:10 비율로 표시한다.
  긴 상단 경로는 한 줄 말줄임으로 처리해 고정 탭과 겹치지 않게 한다.
- 일반 페이지의 전체 폭 배경은 바깥 컨테이너에 적용한다. `100vw` 가상 요소로
  스크롤바 너비까지 확장하지 않는다.
- 회색 면은 기본 정보·비교할 지표처럼 독립된 값 묶음에 사용한다. 요약 전체와 그 안의
  설명을 중첩된 회색 면으로 감싸지 않는다. 회색 정보 박스의 모서리는 `--ds-radius-lg`로 맞춘다.
- 미술품 요약은 설명·세 가지 핵심 근거·항목별 분석 순서로 배치한다. 근거의 제목은 H4,
  확인한 내용은 본문 크기, 한계·해석은 보조 설명으로 구분한다. 항목별 분석은 행 전체가 링크이며,
  화살표와 hover·키보드 포커스로 이동 가능함을 표시한다.
- 검증 방법의 페이지 제목은 카테고리 목록과 같은 H2 크기·보통 굵기다. 섹션 제목은 H3,
  항목 제목은 H4·굵게, 설명은 `--ds-text-base`·보통 굵기로 표시한다. HTML 제목 단계는 h1 → h2 → h3를 유지한다.
- 검증 방법은 `공통 · 미술품 · 한우 · 한돈 · 부동산` 탭으로 구성한다. 각 탭의 섹션은
  `--ds-line-strong` 1px 구분선과 위아래 `--ds-content-gap`으로 구분한다. 검증 단계와 정정 통계에는
  R 12px 회색 면을, 판정에는 작은 상태 배지를 사용한다. 데이터 출처·작성 원칙·검증 한계는
  항목·설명 행을 공유하고 모바일에서는 위아래로 배치한다.
- 카테고리 설명을 탭에 넣을 때는 `CategoryAboutView`의 `embedded` 양식을 사용한다.
  중복 좌우 여백과 대표 사진을 추가하지 않고 기존 도식·설명·검증 범위를 표시한다.
  본문 바로가기의 해시는 해당 탭을 열며, 상단 고정 탭 아래에 제목이 보이도록 스크롤 여백을 둔다.


## 설명 영역 가독성·구간 구성 (2026-09-06)

- 본문, 항목 설명, 표의 값과 필드 라벨은 `--ds-text-base`를 사용한다. 출처·기준일·상태 배지만
  `--ds-text-xs`를 사용한다. 모바일에서도 본문을 보조 글씨 크기로 줄이지 않는다.
- 제목은 기존 `--ds-heading-*` 역할을 따른다. 페이지별 임의 clamp로 제목 크기를 재정의하지 않는다.
- 항목별 설명은 한우 공모 단계 카드를 공통 기준으로 삼는다. 연한 배경 구간 안에 흰 패널을 두고,
  `--ds-space-5` 간격, `--ds-space-5`~`--ds-space-6` 안쪽 여백, `--ds-radius-xl` 모서리를 사용한다.
  비교표의 행 구분선과 판정색은 유지하되 설명을 테두리만으로 구획하지 않는다.
- 글자가 들어간 설명 이미지를 축소해 본문을 대체하지 않는다. 제목·설명은 HTML로 배치하고,
  이미지가 이해를 돕는 경우에만 본문과 겹치지 않는 별도 영역이나 우측 하단에 둔다.
- 출처, 실제 관측·시나리오 구분과 확인 한계는 유지한다. 도표를 반복 설명하는 안내 문구는 넣지 않는다.

- 가격·금액을 크게 표시하는 카드 값은 `--ds-heading-h4`와 `--ds-weight-regular`를 사용한다.
  본문·표·차트의 작은 금액 표시는 기존 크기를 유지하고 굵게 강조하지 않는다.
