# DAKER 사용 데이터와 법적 검토

## 현재 범위

이 문서는 미술품 조각투자 화면과 검증 저장본에 연결된 데이터만 다룬다. 원문 전체, 이미지, PDF 표 디자인, 회원·세션·개인 답안은 저장하거나 재배포하지 않는다.

## 데이터셋

| 데이터 | 처리 원칙 |
| --- | --- |
| `data/products.json` | 미술품 현재 상품 5건. 원문 링크와 구조화된 일부 사실값만 사용한다. |
| OpenDART | 서버 전용으로 접수번호의 원문 ZIP·XML 수신만 확인한다. 자동 추출·검산 전 금액은 저장 수치다. |
| `data/artnguide_track_records.json` | 플랫폼 자체 게시 이력 187건. 외부 매각·정산을 독립 검증하지 않는다. |
| `data/weshareart_research.json` | 지난 공동구매 145건과 읽기 전용 적합성 테스트 10문항. 통화와 인증 필요 매각 상세를 추정하지 않는다. |
| `data/tessa_sale_records.json` | 매각대금 정산 공시 6건. 원문 수익률과 DAKER 계산값을 분리한다. |
| `data/artnguide_due_diligence.json` | 작가명 정규화·식별 상태를 Next repository, UI와 API의 보강 근거로 연결한다. 원본 파일 자체는 Python 서버와 `/live`에서 직접 제공하지 않는다. |

## 공통 원칙

- 원문 출처, 기준일, 수집 시각, 방법, 한계를 함께 보존한다.
- 공시 제출인 주장, 플랫폼 자체 게시값, 공공 자료, DAKER 계산을 서로 다른 필드와 화면 영역으로 분리한다.
- 출처 링크는 재배포 또는 상업 이용 허락을 뜻하지 않는다.
- 공개·상용화 전 각 제공자의 구조화 저장, 파생 통계, 화면 표시 범위와 금융규제 적용을 별도로 검토한다.
- OpenDART 인증키를 브라우저, 저장소, API 응답 또는 로그에 노출하지 않는다.

## 출시 전 확인

1. 금융규제와 개인화 범위를 검토한다.
2. KYS 및 플랫폼 자체 게시 자료의 이용 범위를 문서화한다.
3. DART 원문 자동 추출을 추가할 경우 정정·복수 시리즈 표를 안전하게 검산하고 저장 수치와 구분한다.
4. 개인정보·회원·세션 데이터 미수집 경계를 회귀 테스트로 유지한다.
