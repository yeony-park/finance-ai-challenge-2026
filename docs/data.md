# DAKER 사용 데이터와 법적 검토

## 0. 문서 정보

- 기준일 : 2026-08-08 KST
- 대상 : 현재 로컬 MVP가 조회·저장·계산하는 데이터
- 목적 : 팀원이 데이터 출처, 수집 방식, 이용 범위와 공개 전 법적 조치사항을 확인하기 위한 문서
- 주의 : 아래 내용은 공개된 법령과 이용조건을 바탕으로 한 제품 위험 점검이며 변호사의 법률의견이 아니다.

## 1. 현재 판단

[확인된 사실]

- 국토교통부 상업·업무용 실거래가 OpenAPI는 공공데이터포털에서 `이용허락범위 제한 없음`, 무료로 제공된다.
- OpenDART는 개인·기업·기관 누구나 이용할 수 있고 공시보고서 원문에서 필요한 자료를 추출해 사용할 수 있다고 안내한다. 인증키, 이용횟수와 약관 준수는 필요하다.
- SOU 약관은 회사 서비스에서 얻은 정보를 사전 승낙 없이 복제·유통하거나 상업적으로 이용하는 행위를 제한한다.
- 투게더아트 약관은 회원에게 제공하는 데이터·소프트웨어·출판물 등에 관한 권리가 회사에 귀속된다고 정한다.
- 한국미술시가감정협회는 2025년 경매시장 결산 PDF를 공개했지만, 제품·상업적 재배포를 허용하는 별도 라이선스는 확인하지 못했다.
- 현재 저장 데이터에는 개인 이름, 전화번호, 계좌번호가 없다. RTMS의 일반건축물 지번은 개인정보보호 목적으로 일부 마스킹돼 있다.

[법적 위험 판단]

- 현재 로컬 내부 검증용 MVP는 원문 전체를 재배포하지 않고 필요한 사실값·계산값·원문 링크만 표시하므로 위험을 낮춘 상태다.
- 공개 또는 상용 서비스로 바로 배포하기에는 법적 확인이 부족하다. 특히 SOU 자동수집, KYS 데이터 구조화, 투게더아트 페이지·PDF 재사용은 이용허락이 확인되지 않았다.
- 따라서 현재 상태를 `법적 문제 없음`으로 판정하지 않는다. 공개 출시 전 SOU·KYS의 서면 이용허락, 투게더아트 자료 사용범위 확인, 금융규제 검토가 필요하다.

[상품 6·7 금액 용어]

- 공모 원문의 명칭은 `관리처분신탁 관련 위탁수익금`이다. 상품 6은 1,400,000,000원, 상품 7은 2,790,000,000원이다.
- 공모 원문은 이를 위탁자의 위탁수익권에 대한 대가로 정의한다. DAKER는 이 금액을 독립 확인된 부동산 취득가로 표시하지 않는다.

[확인된 사용 제한]

- SOU 서비스 이용약관은 서비스에서 얻은 정보를 회사의 사전 승낙 없이 복제·유통하거나 상업적으로 이용하는 행위를 제한한다.
- 공식 홈페이지 하단은 `All rights reserved`로 표시한다.
- endpoint 경로에 `public`이 포함되고 인증 없이 응답한다는 사실만으로 재배포·상업 이용 허락까지 확인되는 것은 아니다.

[필요 조치]

- 외부 공개 전 루센트블록에 다음 범위의 서면 허락을 요청한다 : 공개 API 자동조회, 24시간 캐시, 일부 필드 저장, 파생 통계 생성, 상업 서비스 화면 표시.
- 허락 전에는 내부 데모로 제한하거나 SOU 원문 링크만 제공하고 자동조회·저장 기능을 비활성화한다.
- 로고, 상품 사진, 설명문, 감정평가서 원문 파일은 복제하지 않는다.

[확인된 이용조건]

- 공공데이터포털은 해당 OpenAPI의 이용허락범위를 `제한 없음`으로 표시한다. 2026-07-22 수정, 무료, 개발·운영 자동승인으로 안내한다.
- 개인정보보호를 위해 일반건축물 지번 일부만 제공한다.
- 현재 코드의 세션 기반 CSV 다운로드는 공식 공개 화면의 기능이지만 외부 개발자를 위한 OpenAPI로 문서화된 수집 경로는 아니다.

[필요 조치]

- 현재 `COMMERCIAL_API_KEY`를 공식 OpenAPI 기본 경로로 사용한다. 기존 CSV는 OpenAPI 장애 때만 보조 경로다.
- 화면과 데이터 파일에 `국토교통부 실거래가 공개시스템`, 조회기간과 조회일을 표시한다.
- 마스킹 지번을 다른 자료와 결합해 개인 또는 정확한 거래당사자를 재식별하지 않는다.
- OpenAPI 호출량과 이용조건 변경을 정기적으로 확인한다.

### 2.3 금융감독원 DART·OpenDART

| 항목 | 내용 |
|---|---|
| 제공자 | 금융감독원 DART, 공시 제출인 |
| 현재 수집 방식 | `DART_API_KEY`로 접수번호별 원문 ZIP 수신 여부와 최근 공시 목록을 확인. 금액·작품 행은 기존 원문 확인 뒤 수기 정규화한 저장 수치다. |
| 자동화 제한 | 원문 XML의 정정·중복·복수 시리즈 표를 자동 파싱하지 않는다. 자동 검산 전 저장 수치를 실시간 값으로 표시하지 않는다. |
| 제품 사용값 | 작품 정보, 취득가, 발행비, 공모가, 청약·발행인 인수금액, 발행일, 평가·경매 비교자료 |
| 원문 복제 | 하지 않음. 링크와 구조화된 일부 사실값만 사용 |
| 법적 위험 | 낮음~중간 |

- [투게더아트 9차 최종 투자설명서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260513000002)

[확인된 이용조건]

- OpenDART는 공시보고서 원문을 XML로 내려받아 필요한 자료를 추출해 사용할 수 있다고 안내한다.
- API 이용에는 인증키가 필요하고 이용횟수 제한, 인증키 제3자 제공 금지와 약관 준수가 적용된다.
- 공시정보의 정확성과 완전성은 공시 제출인 책임이며 금융감독원이 보장하지 않는다고 약관에 적혀 있다.

[필요 조치]

- 자동 갱신은 DART 웹 화면 수집 대신 OpenDART 인증키로 구현한다.
- 인증키를 브라우저나 저장소에 노출하지 않는다.
- 공시 원문 전체, 첨부 이미지와 표 디자인을 복제하지 않고 분석에 필요한 사실값과 원문 링크만 제공한다.
- 공시 제출인 주장과 DAKER의 계산·해석을 화면에서 구분한다.

### 2.4 한국미술시가감정협회 KYS 경매시장 결산

| 항목 | 내용 |
|---|---|
| 제공자 | 사단법인 한국미술시가감정협회·아트프라이스 |
| 사용 문서 | 2025년 국내 미술품 경매시장 결산 PDF |
| 수집 방식 | PDF를 확인한 뒤 작가별 수치를 JSON으로 수기 정규화 |
| 제품 사용값 | 출품 수, 낙찰 수, 낙찰률, 낙찰총액, 일부 낙찰행 |
| 원문 복제 | 현재 제품에는 PDF 전체와 표 이미지를 복제하지 않고 링크·일부 수치만 사용 |
| 법적 위험 | 중간~높음 |

원문 :

- [한국미술시가감정협회 공식 홈페이지](https://artprice.kr/)
- [2025년 국내 미술품 경매시장 결산 PDF](https://artprice.kr/data_archive/20260312_132032_cf7c4a16.pdf)

[확인된 사실]

- 협회 홈페이지는 1998년 이후 구축한 보유 자료를 데이터베이스로 소개한다.
- 해당 결산 PDF는 공개 다운로드할 수 있고 보도자료·자료제공 형식이다.
- 확인한 공식 페이지와 PDF에서는 제품 재배포 또는 상업적 API 이용을 명시적으로 허용하는 라이선스를 찾지 못했다.

[법적 위험 판단]

- 작가별 개별 수치 몇 개를 출처와 함께 비평·분석에 사용하는 것과 협회 데이터베이스를 반복적·체계적으로 추출해 대체 서비스를 만드는 것은 위험이 다르다.
- 저작권법 제93조는 데이터베이스의 전부 또는 상당한 부분에 대한 복제·배포·전송 권리를 데이터베이스 제작자에게 인정한다. 개별 소재라도 반복적·체계적 이용으로 통상 이용과 충돌하거나 제작자의 이익을 부당하게 해치면 문제가 될 수 있다.

[필요 조치]

- 현재 KYS 집계값은 기존 3명 작가의 제한된 수치만 유지한다. 새 쿠사마·콘도 상품의 발행인 기재 사례 수는 KYS 독립 통계로 취급하지 않는다.
- PDF, 표, 차트, 작가 전체 순위와 전체 거래행을 자체 데이터셋처럼 재배포하지 않는다.
- 작가·작품 범위를 확대하기 전에 협회에 상업 이용, 구조화 저장, 파생지표 생성 허락을 서면으로 받는다.

### 2.5 건축HUB·VWorld·토지 RTMS

## 5. 팀 운영 규칙

- 데이터 필드마다 `source_url`, `as_of`, `fetched_at`, `mode`를 저장한다.
- `mode`는 `live`, `verified_snapshot`, `manual_normalization`, `unconnected` 중 하나로 표시한다.
- 운영사 제공 정보, 독립 공공자료, DAKER 계산을 서로 다른 필드와 화면 영역으로 분리한다.
- 원문이 삭제돼도 저작권 있는 PDF·이미지를 임의로 공개 저장소에 복제하지 않는다.
- 이용허락이 불명확한 신규 출처는 제품 데이터에 추가하기 전에 이 문서의 위험표를 갱신한다.
- 법적 허락과 데이터 정확성은 별개로 검증한다. 이용 가능한 데이터라도 최신성·표본 적합성이 부족하면 투자판정을 보류한다.

## 6. 현재 결론

- RTMS : 공식 OpenAPI로 전환하고 출처·조회일을 표시하면 이용 위험이 가장 낮다.
- DART : OpenDART 공식 API와 약관에 맞추면 사용 가능성이 높다.
- SOU : 현재 약관상 사전 승낙 없는 복제·유통·상업 이용 제한이 확인돼 공개 상용화 전 서면 허락이 필요하다.
- KYS : 공개 PDF지만 상업적 데이터 재사용 라이선스를 확인하지 못해 서면 허락 전 대량 구조화·재배포는 하지 않는다.
- 투게더아트 : DART로 대체 가능한 정보는 DART를 사용하고, 자체 페이지·PDF는 최소 사실 인용과 링크로 제한한 뒤 사용범위를 확인한다.
- 서비스 출력 : 특정 상품의 가치·투자판단을 유료 또는 개인화해 제공하면 투자자문 규제가 적용될 수 있어 별도 법률검토가 필요하다.
