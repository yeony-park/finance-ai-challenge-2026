# DAKER 합성 데이터와 법적 검토

## 현재 범위

운영 서비스는 OpenDART 서버 기능을 제외한 상품·플랫폼 데이터를 독립 합성 fixture로 제공합니다. 실제 외부 플랫폼 레코드, 이미지, 원본 URL과 raw payload는 서비스 저장소와 배포 산출물에 포함하지 않습니다.

## 데이터셋

| 데이터 | 처리 원칙 |
| --- | --- |
| `data/synthetic/art-investment.json` | 합성 현재 상품 9건과 과거 이력 318건. 실제 상품이나 투자 권유가 아닙니다. |
| `public/synthetic-art/*.svg` | 합성 ID만으로 생성한 로컬 추상 이미지입니다. |
| OpenDART | 서버 전용 코드를 유지합니다. 합성 상품에는 실제 접수번호를 연결하지 않습니다. |

## 생성 원칙

- 실제 행을 복사해 숫자만 변경하지 않습니다.
- 공모금액·취득가·비용·구좌 수의 계산 관계를 유지합니다.
- 플랫폼 유형별 금액과 보유기간 중앙값을 현실적인 구간에 맞춥니다.
- 실제 건수, 순서, 희소 조합과 1:1 대응을 만들지 않습니다.
- 가상 ID·작가·작품·플랫폼·발행사·이미지를 먼저 만들고 수치를 독립 생성합니다.
- `sourcePayload`, 원본 ID, 원격 이미지와 OpenDART 외 외부 URL을 공개 모델에서 금지합니다.
- 모든 화면과 API에 `dataMode: synthetic` 또는 합성 배지를 유지합니다.

## 원본 보관 경계

원본과 오프라인 생성기는 서비스 저장소 밖의 접근 제한 보관소에 둡니다. 운영 앱과 Docker builder는 해당 경로에 접근할 수 없습니다. 공개 저장소 이력이나 기존 배포본에 이미 포함된 자료는 파일 삭제만으로 회수되지 않으므로 별도 이력·cache 정리가 필요합니다.

## 출시 전 확인

1. 합성 source·artifact·Docker 이미지 검사를 모두 통과합니다.
2. API DTO에 금지 필드와 OpenDART 외 URL이 없는지 확인합니다.
3. 실제 상품과 혼동되지 않도록 합성 배지를 확인합니다.
4. 원본 자료의 보관·파생 통계 이용 범위는 별도 법률 검토를 받습니다.
5. Git/CI/registry/CDN의 기존 이력과 cache 정리 상태를 확인합니다.
