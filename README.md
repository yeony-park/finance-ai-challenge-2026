# 2026 금융 AI Challenge

금융보안원 주최 [2026 금융 AI Challenge](https://daker.ai/public/hackathons/2026-finance-ai-challenge) 참가 프로젝트.
AI 기반 금융 현안 해결 웹서비스 MVP를 개발한다. 1차 제출 마감: 2026-09-07(월) 10:00.

## 주제 — 조각투자 공시 대조 검증

발행사가 공시한 내용과 공공 데이터의 일치 여부를 대조하는 독립 검증 레이어.
실물 제시는 발행사 공시가 담당하고, 이 서비스는 공시된 내용이 공공 원장과 일치하는지를 대조한다.

| 층위 | 검증 질문 | 데이터 |
|---|---|---|
| 1. 실재성 | 신고서에 기재된 자산이 실제로 존재하는가 | 축산물이력제 (mtrace.go.kr) |
| 2. 가격 적정성 | 공모가·매각가가 시장 대비 어느 위치인가 | 국토부 실거래가 · 축평원 경락가 |
| 3. 이행·조건 | 공시한 약속의 이행 여부, 불리한 조건의 존재 여부 | DART 전수 + 플랫폼 공시 |

LLM은 비정형 신고서에서 검증 가능한 주장(claim)을 추출하는 역할을 맡는다. 이 추출이 세 층위 정량 대조의 전제가 된다.

상세: [`docs/planning/주제-정의-조각투자-가치검증.md`](docs/planning/주제-정의-조각투자-가치검증.md) · 근거: [`docs/research/조각투자-검증리서치-2026-08-08.md`](docs/research/조각투자-검증리서치-2026-08-08.md)

완료 구간의 주요 결과:

- **S1 엔진 정식화** — 파서 일반화, LLM 추출과 규칙 기반 교차검증, `POST /api/verify/[id]` 라이브 재검증, 공개 슬러그 중립화(`livestock-N`).
- **S2 확장성·감시** — 국토부 RTMS 실수집 기반 부동산 사후 검증(축 B), 경락가 가격 층위, 홈 목록형 개편, 정정 재검증과 cron 감시.
- **S3 제품화** — 리플레이 재생, 관심 등록, LLM 눈높이 서술, 스파인 도메인 교체(레드팀 24건 전건 통과 — [리포트](docs/redteam/report.md)). 자유 대화형 챗봇은 PRD 범위 밖이라 `/api/chat` 제거.
- **S3.5 및 후속** — 성별 수→거세를 예상된 상태 전이로 재분류(오탐 106건 해소, 라이브 재대조 7호 200/200·8호 330/330 일치), 판정 어휘를 "원장 불일치"로 통일, 리포트 위계 역전(정정 계보·트랙레코드 상단, 개체 매트릭스 부록화), 발행사 트랙레코드 요약 카드.
- **커버리지 확장** — 공개 리포트 10건 체제: 2026년 전수 8건 중 대조 가능 전건 3건(가축 7·8·9호) + 종료 공모 사후 검증 7건(가축 1~6호, 부동산 A). 전 건 라이브 재대조·리플레이·내러티브·감시 등록, 익명화 스캔 누출 0건. 신규 실측 신호 4건(2호 원장 미조회, 4·5호 보관장소 불일치).
- **정정 이력 제품화** — 발행사 자필 (주N) 블록 파싱 기반 정정 전→후 발췌와 변경 구간 하이라이트, 정정 기록 문서형 개편, 방법론 단계 리스트, 챕터 네비게이션.

## 빠른 시작

```bash
npm install
npm run dev       # API 키 없이 fake 모드로 동작
npm test          # 스파인 유닛/파이프라인 테스트
npm run redteam   # 자체 레드팀 실행 → docs/redteam/report.md
npm run verify    # 검증 파이프라인 완주 (fake 모드 — 키 없이 동작)
```

경락가 월 집계는 사전 수집 후 커밋한다. 축평원 등급판정정보 개발계정 한도가 일 1,000건이므로
판정·화면·재검증은 캐시(`data/reference/auction-price/`)만 읽는다.

```bash
npm run reference:collect   # 실키 전용 · 호출 수 = 월 수 × 성별 수 (기본 4×3 = 12건)
```

발행사 트랙레코드도 사전 수집 후 커밋한다. 화면은 캐시(`data/public/track-record/{issuerKey}.json`)만 읽는다.

```bash
npm run track-record   # 실키 전용 · DART 공시검색 2회 + 증권발행실적보고서 원문 (계보상 최신본만)
```

실모델 연결은 `.env.example` 참조. 키가 없으면 전 구간 fake 모드로 완주하며, claim 추출은 `AI_GATEWAY_API_KEY` 또는 `OPENAI_API_KEY` 직결을 지원한다(현재 프로덕션은 OpenAI 직결).

> `npm run dev`는 서비스 화면을 띄운다 — 랜딩(`/`), 검증 방법(`/methodology`), 카테고리별 검증 리포트 상세(`/{category}/products/[id]`).
> 화면에 찍히는 수치·문구는 전부 검증 엔진 산출 리포트(`data/public/{offerId}/report-*.json`)에서 파생되며 익명화가 적용된 상태다.
